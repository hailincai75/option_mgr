## 背景 / 用户故事
用户对照券商页面（2026-11-15）：券商对每一笔开仓批次都显示未实现盈亏，我们的持仓页只在持仓行上显示（FEAT-017），展开批次只看到净额。平仓是 FIFO 整笔平最早的批次（Q21），所以平 1 张时真正实现的是最早那笔的盈亏——持仓整体赚钱时，最早那笔可能是亏的。

作为一个期权交易者，我想在持仓页展开批次时看到每个批次的市值、未实现盈亏和百分比，以便知道下一次平仓会实现多少。

## 已定的口径（只引用）
- Q21：期权平仓整笔平掉最早的批次，批次没有部分平仓（期权批次的剩余净额 = 原净额）。
- Q69 / Q87：股票批次可部分卖出，批次有剩余股数、剩余成本。
- Q152：期权市值带方向（多头正、空头负），未实现 = 开仓净额（空头 +、多头 −）+ 市值。Q153：不预估平仓手续费。
- Q154：市值四舍五入到分，盈亏用取整后的市值算。Q155：百分比 = 未实现 ÷ |开仓净额|（股票 ÷ 成本），2 位小数、带符号，分母 0 显示 `—`。
- Q156：已过期未处理不计算，显示 `已到期，待处理`。Q162：市值带显式正负号。
- Q161：场景只用 multiplier 100。Q214 / Q215：全部账户模式下按账户分行。
- Q237：股票批次也显示。Q238：最后一个批次取余数，合计等于持仓行。Q239：不可计算 / 旧报价时完全跟随持仓行。Q240：百分比分母多空同一口径（同 Q155）。Q241：持仓行不加"最早批次"提示。

## 规则
1. **范围**：期权持仓的每个批次（FEAT-003 批次表），以及股票持仓的每个批次（FEAT-011 批次表，Q237）。持仓行上的市值、未实现、百分比和合计（FEAT-017）**完全不变**。
2. **批次市值**：期权 = mark × 批次剩余张数 × multiplier，带持仓方向（Q152）；股票 = 现价 × 批次剩余股数。mark / 现价与持仓行用的是同一个值。
3. **取整与对齐**（Q238）：按 FIFO 顺序，除最后一个批次外，每个批次市值按规则 2 四舍五入到分；**最后一个批次 = 持仓市值（FEAT-017）− 其它批次市值之和**。因此各批次市值之和、各批次未实现之和**始终等于**持仓行的值。（只有 1 个批次时批次值 = 持仓值；价格乘出来本来就是整分时，与各自取整结果相同。）
4. **批次未实现盈亏**：期权 = 批次剩余开仓净额（空头 +、多头 −）+ 批次市值；股票 = 批次市值 − 批次剩余成本。
5. **批次百分比**（Q240）：期权 = 批次未实现 ÷ |批次剩余开仓净额|；股票 = 批次未实现 ÷ 批次剩余成本；多头空头同一公式；取整与 `—` 同 Q155。
6. **无法计算**（Q239）：持仓行显示 `无报价` 或 `已到期，待处理` 时，它的每个批次的市值、未实现都显示同样文字；持仓行用上次报价计算时（`行情未更新`、`数据源已无该合约`），批次也用同一个 mark 计算。
7. 所有计算只在后端做；前端只显示后端给的值和文字。

## 需要的数据和操作（给 backend）
- 期权持仓、股票持仓的每个批次加：市值、未实现盈亏、百分比（规则 2–5），以及不可计算时的原因（规则 6，与所属持仓相同）。
- 全部账户模式（FEAT-035）下批次数据照常返回，值与单账户相同。
- 不需要新的写操作，不存库；交易、平仓、到期处理、修改 / 删除、行情刷新、手动覆盖之后重新查询即得到新值。

## 页面与交互（给 frontend）
- **期权批次表**（持仓页展开）：在 `剩余开仓净额` 后加 `市值`、`未实现盈亏` 两列，格式与持仓行相同（市值带显式符号；盈亏正绿负红、下面小字百分比）；不可计算时两列显示后端文字，灰色。
- **股票批次表**：在 `剩余成本` 后加同样两列（Q237）。
- 持仓行、顶部合计、策略页不变。全部账户模式下批次展开照常显示这两列。
- 切换账户、立即刷新、设置 / 清除手动值、任何写操作之后，展开中的批次表随持仓重新查询更新。

## 验收标准
场景（所有条目共用）：今天 2026-11-16（星期一）10:00 拉取成功，标的为虚构的 ZZQ，multiplier 100，现金充足。
甲账户：
- C：空头 ZZQ 2026-12-18 9C，批次 A = STO 1 张 2026-11-10 10:00 净额 18.34，批次 B = STO 1 张 2026-11-11 10:00 净额 37.34；bid 0.10 / ask 0.30（mark 0.20）。
- P：多头 ZZQ 2026-12-18 8P，批次 L1 = BTO 1 张 2026-11-12 10:00 净额 25.65，批次 L2 = BTO 2 张 2026-11-13 10:00 净额 41.30；bid 0.15 / ask 0.19（mark 0.17）。
- ZZQ 股票 200 股：S1 = 转入 2026-10-01 100 股 成本 950.00，S2 = 买入 2026-11-03 10:00 100 股 780.65；现价 8.65。

乙账户：ZZQ 股票 200 股：S3 = 买入 2026-11-04 10:00 101 股 880.00，S4 = 买入 2026-11-05 10:00 99 股 860.00。

1. **空头批次**：**When** 打开甲账户持仓页 **Then** C 行仍为 市值 `−40.00`、未实现 `+15.68`（`+28.16%`）；**When** 展开 C **Then** A：市值 `−20.00`、未实现 `−1.66`（`−9.05%`）；B：市值 `−20.00`、未实现 `+17.34`（`+46.44%`）。
2. **多头、张数不同的批次**：**Then** P 行 市值 `+51.00`、未实现 `−15.95`（`−23.82%`）；展开 P：L1 市值 `+17.00`、未实现 `−8.65`（`−33.72%`）；L2 市值 `+34.00`、未实现 `−7.30`（`−17.68%`）。
3. **股票批次**：**Then** 甲账户 ZZQ 股票行 市值 `+1,730.00`、未实现 `−0.65`（`−0.04%`）；展开：S1 市值 `+865.00`、未实现 `−85.00`（`−8.95%`）；S2 市值 `+865.00`、未实现 `+84.35`（`+10.81%`）。
4. **FIFO 平仓实现的是最早批次**：**When** 甲账户 BTC 1 张 ZZQ 2026-12-18 9C、净额 20.65 **Then** 已平仓记录该笔盈亏 `−2.31`（平掉 A）；C 变为 1 张，行和唯一批次 B 都是 市值 `−20.00`、未实现 `+17.34`（`+46.44%`）。
5. **mark 变化**：**When** 把 C 的 Mark 手动设为 0.35 **Then** C 行 市值 `−70.00`、未实现 `−14.32`（`−25.72%`）；A 市值 `−35.00`、未实现 `−16.66`（`−90.84%`）；B 市值 `−35.00`、未实现 `+2.34`（`+6.27%`）。**When** 清除手动值 **Then** 恢复验收 1 的数字。
6. **无法计算与旧报价**：**Given** 甲账户另有 STO 1 张 ZZQ 2026-12-18 7P 净额 12.00（链中从无该合约），以及 STO 1 张 ZZQ 2026-11-13 8P 净额 15.00（已过期未处理）**When** 展开这两行 **Then** 7P 批次两列显示 `无报价`，8P 批次两列显示 `已到期，待处理`。**When** 10:15 起 ZZQ 拉取失败（行上 `行情未更新`）**Then** A、B 仍显示 `−1.66`、`+17.34`。
7. **取整对齐**：**When** ZZQ 现价变为 8.655 后切到乙账户 **Then** ZZQ 股票行 市值 `+1,731.00`、未实现 `−9.00`（`−0.52%`）；展开：S3 市值 `+874.16`、未实现 `−5.84`（`−0.66%`）；S4 市值 `+856.84`、未实现 `−3.16`（`−0.37%`）。
8. **股票部分卖出后**：**Given** 验收 4 之后（C 只剩 1 张，覆盖 100 股）**When** 甲账户卖出 ZZQ 50 股、实收 440.00 **Then** 股票行 150 股、市值 `+1,297.50`、未实现 `+41.85`（`+3.33%`）；S1 剩 50 股、剩余成本 475.00、市值 `+432.50`、未实现 `−42.50`（`−8.95%`）；S2 不变 `+84.35`。
9. **全部账户**：**When** 选 `全部账户` 并展开 `甲账户` C、`乙账户` ZZQ 股票 **Then** A、B 同验收 1；S3 市值 `+873.65`、未实现 `−6.35`（`−0.72%`），S4 市值 `+856.35`、未实现 `−3.65`（`−0.42%`），乙账户股票行未实现 `−10.00`（`−0.57%`）；页面没有写操作按钮（FEAT-035）。

## 边界情况
- **只有 1 个批次**：批次值与持仓行完全相同（验收 4）。
- **同一时间的多个批次**：先录入的在前（Q19），最后一个批次取余数（规则 3）。
- **mark 为 theo、到期日当天**：与持仓行相同，照常计算。
- **被 covered call 覆盖的股票批次**：照常计算，不区分是否被覆盖。
- **成本为 0.00 的转入批次**：百分比 `—`（Q155）。
- **补录、修改、删除交易**：重放后批次变化，值随之重算（同验收 4、8）。
- **被指派 / 行权得到的股票批次**：剩余成本已含权利金调整（Q8 / Q111），照常计算。

## Out of Scope
- 持仓行、合计、首页、策略页（FEAT-021 / 023）卡片的任何改动。
- 按批次的 Greeks；按批次的"持有天数"、年化收益。
- 预估平仓手续费（Q153）；指定批次平仓（只支持 FIFO，Q21）。
- 已过期合约按内在价值估算（Q156）。
- 持仓行上的"最早批次盈亏"提示（Q241）。
