# FEAT-013: 卖出 put 被指派

- **Status:** Verified
- **Priority:** P0
- **Depends on:** FEAT-011（股票交易与持仓）、FEAT-012（到期作废）——都已 Verified；沿用 FEAT-004（整笔平仓 Q21）、FEAT-005（修改/删除/审计）、FEAT-006/040（已平仓、汇总）、FEAT-007（现金）、FEAT-033（多账户）
- **Scope:**
  - [x] Backend: Done
  - [x] Frontend: Done

> **拆分说明：** 原 FEAT-013 包含 put 和 call 两种被指派。按"验收标准 8–10 条"的规则，两者合在一起约 16–18 条（put：按钮时间窗、成本口径、冻结现金买股、指派费、整笔批次、提前指派、与作废的先后、删除、修改之前交易的重放、多账户；call 又要加：持股检查 Q75、股票 FIFO 卖出与部分卖出分摊、权利金并入卖出实收、与之后股票买卖的重放、已平仓页股票行），超出一次会话。因此拆为：
> - **FEAT-013（本需求）= 卖出 put 被指派**：用冻结现金买入股票，生成一个股票批次。
> - **FEAT-041 = 卖出 call 被指派**（P0，依赖 013、011）：按行权价按 FIFO 交出股票，复用本需求的记录形式、按钮、时间、删除和重放规则。
>
> 本需求里空头 call 行**没有**"被指派"按钮（FEAT-041 加）。

## 背景 / 用户故事
作为一个卖 cash-secured put 的期权交易者，我的 put 有时会被指派：到期时价内被指派，或者到期前被提前指派（美式期权）。被指派后我按行权价买入股票，用的就是卖 put 时冻结的担保现金。我的券商 把卖 put 收到的权利金从股票成本里扣掉：股票成本 = 行权价 × 股数 − 权利金，期权本身不再单独计盈亏。

我想在持仓页的空头 put 行上点"被指派"，填指派日期（默认到期日）、选张数、可选填指派费，系统就：把这些张数的期权持仓清掉（期权已实现盈亏记 0.00），用这些批次冻结的现金按行权价买入股票，生成一个成本已扣除权利金的股票批次，之后卖出这些股票时，股票的已实现盈亏里自然包含了权利金。记错了可以删除，一切恢复原样并留下审计。

（我账户里有 2026-11-20 到期的期权；在本需求上线之前被指派的持仓保持"已过期"，上线后按指派日期补记，Q76。）

## 已定的口径
来自 backlog Open Questions，本需求新定的：
- **Q8（用户决定，与 PM 原建议不同；理由：与用户的券商 的做法一致）put 被指派的成本**：
  - 股票成本 = 行权价 × 股数 − 被指派批次的开仓净额之和（即实收权利金，已扣开仓手续费，Q6）+ 指派费（Q74）。
  - 期权一侧的已实现盈亏记 **0.00**——权利金转入股票成本，等这些股票卖出时体现在股票的已实现盈亏里。
  - 例：STO 1 张 XYZ 2026-11-20 45 P 净收 120.00 被指派、指派费 0.00 → 期权已实现 0.00；股票 100 股，成本 4,380.00（每股 43.8000）。
  - call 被指派的口径（权利金并入卖出实收，**暂定**）在 FEAT-041，不在本需求。
- **Q11（A）只支持股票 / ETF 期权（实物交割）**：被指派一律交割股票。系统不区分标的是否是指数，用户目前不做指数期权；如果以后开始做（如 SPX，现金结算），重新讨论（见 backlog Q11 备注）。
- **Q73（用户决定）不拆分批次**：被指派与平仓一样遵守 Q21——张数必须**正好等于该合约在指派时点最早的 1 笔或连续多笔整批次之和**，否则拒绝。用户卖 put 时券商总是冻结全部所需现金，从未遇到过部分指派。**备注：** 如果以后真的发生"合并的多张批次只被指派一部分"，再重新讨论（例如允许指派拆分批次）。
- **Q74（按建议）现金与指派费**：
  - put 被指派 → 用被指派批次冻结的现金买股：总现金 −（行权价 × 股数），冻结 −（被指派批次的冻结之和），可用基本不变（差异只来自取整，见 Q96）。
  - 可选填一个**指派费**，默认 `0.00`：加进股票成本，并从现金中扣（总现金、可用各 −指派费）。
  - 例：XYZ 45 P 1 张被指派、费用 0.00 → 总现金 −4,500.00、冻结 −4,500.00、可用不变；股票 +100 股，成本 4,500.00 − 权利金。费用 5.00 → 成本再 +5.00，可用 −5.00。
- **Q75** 只涉及 call，在 FEAT-041。
- **Q76（A，用户已确认）指派时间**：用户填**指派日期**（美东），时间固定为该日**美东 16:00**；默认到期日；可以早于到期日（提前指派），**不能晚于到期日**；可以补记过去的日期，按 Q19 重放检查。例：XYZ 2026-11-20 45 P 在 11-18 被提前指派 → 填 11-18，记在 2026-11-18 16:00（`2026-11-18T21:00:00Z`）；11-20 到期被指派但 12-02 才录 → 填 11-20。

- **Q94（A，按建议）** 指派日期选今天、但现在还不到美东 16:00 时：拒绝（记录时间不能晚于当前时间），今天的日期从 16:00 起才能选。例：11-19 10:00 填 11-19 → 拒绝；填 11-18 → 记在 11-18 16:00。
- **Q95（A，按建议）** "被指派"按钮在空头 put 行上**任何时候**都显示，包括到期日 16:00–17:30 的"到期待确认"期间（此时它是唯一的按钮）。
- **Q96（A，按建议）** 行权价 × 股数不是整分时，买股金额**向上取整到分**（与冻结的 Q28 一致）。例：12.345 × 1 → 12.35；12.345 × 2 = 24.69。
- **Q97（A，按建议）** 被指派记录在已平仓页显示为一行（已实现盈亏 0.00），**计入笔数**（盈亏汇总、首页的笔数同样计入）。
- **Q98（A，按建议）** 被指派时可以填一条**可选备注**（≤ 500 字符）。

沿用的口径：
- 一张合约 = multiplier 股（不写死 100）；股数 = 张数 × multiplier
- 空头 put 被指派时释放该批次冻结的现金（Q13）；释放额 = 被指派批次的冻结之和（每笔开仓已按 Q28 向上取整，不重新计算）
- 按 `(时间, 录入顺序)` 重放；补录、修改、删除都把改动应用到全部历史上重放，任何一笔记录或任何一个时点不成立就整笔拒绝（Q19、Q27、Q39、FEAT-005、FEAT-012）
- 被指派得到的股票是一个普通的股票批次：参与 FEAT-011 的 FIFO、部分卖出按比例分摊（Q69、Q87），卖出的已实现盈亏进入已平仓页、盈亏汇总、首页（FEAT-040）
- 新增不写审计，修改/删除写审计；连带改正写进同一条审计的"连带变化"（Q42）；"历史"入口只对有审计记录的行显示
- 到期作废规则不变（Q9、Q10、Q63–Q66、Q83）；部分被指派时先记指派、再作废剩余（Q65）
- 所有规则按账户独立（Q53）；股票只进入同一账户
- 前端不做任何金额、成本、股数、盈亏、冻结计算

## 需要的数据和操作（给 backend）

### 被指派记录
一次被指派 = 一条期权记录（与开仓/平仓/到期作废并列的一种，方向"被指派"）+ 一条由它生成的股票记录 + 一条现金流水，三者同生同灭。

| 数据 | 规则 |
|------|------|
| 所属账户 | 当前账户（Q53），不能改 |
| 合约 | 标的、到期日、行权价、Put（本需求只接受 put） |
| 方向 | "被指派"。被指派的持仓必须是空头 put |
| 张数 | 用户选择；必须是指派时点最早 1 笔或连续多笔整批次之和（Q73 / Q21） |
| multiplier | 取持仓的（同平仓） |
| 指派日期 | 用户填（美东日期），默认到期日；≤ 到期日（Q76）；该日 16:00 不能晚于当前时间（Q94） |
| 时间 | 指派日期美东 16:00，存 UTC（例：2026-11-20 → `2026-11-20T21:00:00Z`；2027-03-19（夏令时）→ `2027-03-19T20:00:00Z`） |
| 指派费 | 可选，默认 `0.00`；≥ 0，最多 2 位小数，上限同 Q29 净额 |
| 备注 | 可选，≤ 500 字符（Q98） |
| 净额 | 恒为 `0.00`（期权本身没有收付） |
| 期权已实现盈亏 | 恒为 `0.00`（Q8） |
| 录入顺序 | 与交易、作废、股票记录、入金/出金共用"同一时间按录入顺序" |

由此得出（后端计算，读取时按重放得出，补录/修改/删除后自动按新匹配）：
- **被指派批次**：按 FIFO 匹配的整笔开仓批次（每批：开仓交易 ID、开仓时间、方向、张数、开仓净额、冻结）。
- **股数** = 张数 × multiplier。
- **买股金额** = 行权价 × 股数，不是整分时向上取整到分（Q96）。例：45 × 300 = 13,500.00；12.345 × 2 = 24.69。
- **释放冻结** = 被指派批次的冻结之和。
- **权利金** = 被指派批次开仓净额之和。
- **股票成本** = 买股金额 − 权利金 + 指派费。必须 > 0.00，否则拒绝（与股票金额必须 > 0 的规则一致；正常数据不会出现，因为 put 的权利金小于行权价 × 股数）。
- **现金变动** = −（买股金额 + 指派费）；**冻结变动** = −释放冻结；可用变化 = 释放冻结 − 买股金额 − 指派费。

### 生成的股票记录
- 一种新的股票记录类型 **"指派买入"**（与买入 / 卖出 / 转入并列）：标的 = 合约标的，股数，成本 = 股票成本，时间 = 指派时间（指派日期 16:00），能关联到被指派记录（ID）。
- 它是一个普通批次，按它的时间排进该标的的 FIFO（Q86 同样的原则：按时间，不是排在最前）；之后的卖出可以用它，部分卖出按 Q69、Q87 分摊。
- **不能单独修改或删除**：请求修改 / 删除它 → 拒绝，提示"该股票记录由被指派生成，请在交易列表删除对应的被指派记录"。它的成本随被指派记录重新计算（例如修改了被指派批次的开仓净额）。
- 没有自己的现金流水（现金在被指派的那条流水里），"有审计记录"恒为否。

### 现金流水
- 每次被指派一条流水：时间 = 指派时间，来源类型"被指派"，金额 = 现金变动（如 `−13,500.00`），冻结变动 = −释放冻结，说明如 `被指派 3 张 XYZ 2026-11-20 45 P，买入 300 股 XYZ`（multiplier ≠ 100 时在合约后加 `（multiplier 1）`，同 FEAT-012），带备注（如有）。
- 关联到被指派记录；没有修改/删除按钮（到交易列表删除）。
- 补录/修改/删除使买股金额或释放冻结变化时，改正这条流水（同 FEAT-012 对 `到期作废` 流水的做法）。

### 操作 1：记录被指派
输入：合约、张数、指派日期、指派费（可空 = 0.00）、备注（可选）。

按顺序检查，任一失败就整笔拒绝、什么都不保存，返回能直接给用户看的中文原因（字段错误指出字段）：
1. **字段**：张数为正整数；指派费格式；备注长度；日期格式。
2. **只能是空头 put**：指派时点持有的是多头（call 或 put）→ 拒绝"多头持仓不能被指派（主动行权见 FEAT-014）"；否则该合约是 call → 拒绝"卖出 call 的被指派暂不支持（FEAT-041）"。
3. **日期**：指派日期 > 到期日 → 拒绝"指派日期不能晚于到期日（2026-11-20）"；指派日期 16:00 晚于当前时间 → 拒绝"指派日期为今天时，美东 16:00 之后才能记录"（日期在未来时："指派日期不能晚于今天"）（Q94）。
4. **有持仓**：把本次插入该合约历史，按 `(指派时间, 录入顺序)` 重放，在指派时点该合约有空头持仓，否则拒绝"2026-11-02 16:00 时该合约（XYZ 2026-11-20 45 P）没有持仓可被指派"；如果原因是该合约已在该时点之前（或同一时间更早录入）到期作废，提示末尾加"（已于 2026-11-20 16:00 到期作废；如果实际是被指派，请先删除该到期作废）"。
5. **整笔批次（Q73 / Q21）**：张数不超过当时持仓，且正好是最早 1 笔或连续多笔整批次之和，否则拒绝，如"必须一次被指派整笔开仓：最早一笔是 2 张，可为 2 张或 3 张"；超过持仓"被指派 4 张超过当时持仓 3 张"。
6. **之后的同合约记录**：插入后该合约之后的平仓、到期作废、被指派按新 FIFO 重新检查（有持仓、不超量、整笔批次），违规则拒绝，文案同 FEAT-012"与其它操作的交互"（如"补录后该合约（XYZ 2026-11-20 45 P）在 2026-11-20 16:00 的到期作废 3 张将超过当时持仓 1 张，请先删除该到期作废"）。
7. **股票成本 > 0**：否则拒绝"被指派后股票成本将为 −12.00，请检查被指派批次的开仓净额"。
8. **现金（Q19）**：插入现金流水后从指派时间起每个时点总现金、可用现金 ≥ 0，否则拒绝，如"可用现金不足：需要 5.00；2026-11-20 16:00 时可用现金将变为 −5.00"（FEAT-011 买入的文案风格；只可能因指派费或取整差异发生）。

保存成功后的效果：
- 被指派批次从期权持仓中移除（剩下的批次照常为持仓，可以平仓、作废或再次被指派）。
- 生成"指派买入"股票记录（新批次）；股票持仓增加。
- 新增一条"被指派"流水；冻结从指派时间起释放，买股金额和指派费从该时间起扣除。
- 不写审计（新增），"有审计记录"为否。
- 返回：合约、张数、指派时间（UTC + 美东）、指派费、被指派批次、权利金、股数、买股金额、股票成本、每股成本（4 位小数，Q88）、现金变动、冻结变动、期权已实现盈亏 `0.00`、生成的股票记录 ID、备注。

### 操作 2：删除被指派记录
- 与 FEAT-005 / FEAT-012 删除相同的原则：把删除应用到全部历史上重放：
  - **合约重放**：被指派批次恢复为持仓；之后同合约的记录按新历史重新检查（例：之后有一条到期作废覆盖剩余批次，删除被指派后作废不再是整笔批次 → 拒绝，提示先删除该到期作废）。
  - **股票重放（Q15）**：生成的股票批次消失，之后该标的的每一笔卖出仍不能超过当时持股，否则拒绝，文案同 FEAT-011（如"删除后 2026-11-24 10:00 的卖出 XYZ 100 股将超过当时持股 0 股"）。
  - **现金重放（Q19）**：现金和冻结从指派时间起恢复，之后每个时点总现金、可用现金都不能为负，否则拒绝，提示时点和金额。
- 成功：被指派记录、生成的股票记录、流水一起删除；之后用到该批次的股票卖出不可能存在（否则已被拒绝）；写**一条**审计记录（对象 = 期权交易 + 被指派记录 ID，操作"删除"，摘要如 `被指派 XYZ 2026-11-20 45 P 3 张（买入 300 股 XYZ）`），修改前的完整内容：合约、方向"被指派"、张数、multiplier、指派日期 / 时间、指派费、备注、净额 `0.00`、股数、买股金额、股票成本、生成的股票记录 ID、现金变动、冻结变动；连带变化同 FEAT-005。
- 删除后可以重新记录（新记录、新 ID，没有审计记录）。
- **不提供修改**（同 Q66 的做法：记错删掉重记）：请求修改被指派记录 → 拒绝"被指派不能修改，记错请删除后重新记录"。

### 与其它操作的交互（补录 / 修改 / 删除之前的交易）
统一原则：**把改动应用到全部历史上（包括被指派记录和它生成的股票批次），按 `(时间, 录入顺序)` 重放，任何一笔不成立就整笔拒绝。** 被指派记录在合约重放里被当作"一笔平掉 N 张的记录"（同 FEAT-012 的到期作废）：

| 改动 | 结果 |
|------|------|
| 修改被指派批次的净额 | 允许；权利金变化 → 股票成本变化 → 之后用到该批次的股票卖出的盈亏随之变化；连带变化写入审计（见下） |
| 删除被指派的开仓，或把它的张数改小 | 被指派张数超过当时持仓 → 拒绝，如"该开仓被 2026-11-20 16:00 的被指派 3 张覆盖（删除后被指派将超过当时持仓 2 张），请先删除该被指派" |
| 修改开仓张数使被指派不再是整笔批次 / multiplier 不一致 | 拒绝（Q21 / Q23），文案同上风格 |
| 修改开仓张数，被指派仍是整笔批次但覆盖的批次变了 | 允许，按新 FIFO 重新匹配（股数不变，权利金、释放冻结、股票成本随之变化） |
| 补录 / 修改 / 删除指派时间之前的同合约开仓、平仓 | 被指派仍成立 → 允许；否则拒绝，提示先删除该被指派 |
| 补录 / 修改 / 删除该标的的股票记录 | 按 FEAT-011 规则；被指派生成的批次照常参与 FIFO |
| 同一时间（指派日期 16:00）的其它记录 | 按录入顺序：在被指派之后录入的、时间正好 16:00 的同合约平仓若因此没有持仓 → 拒绝；同标的的股票卖出在被指派之后录入时可以用到该批次 |
| 改动其它合约、入金/出金 | 只受 Q19 现金重放约束；被指派的流水参与重放 |

- 连带变化（Q42 的延伸）：修改/删除较早的交易使被指派记录的**冻结变动或股票成本**改变时，写进那次修改/删除的审计"连带变化"，如 `被指派 #9 冻结变动 −13,500.00 → −13,500.00`（不变不写）、`被指派 #9 股票成本 13,130.00 → 13,125.00`。

### 与到期作废的先后（FEAT-012）
- 同一批次不可能既被作废又被指派：两者都按 FIFO 整笔匹配、都要求当时有持仓，重放自然保证。
- **到期当天被指派、剩余作废（Q65）**：先记被指派（日期 = 到期日，16:00），再作废——作废排在后面（同为 16:00，后录入），覆盖剩下的批次。
- **已经作废了、才发现其实被指派**：被指派日期 = 到期日时排在作废之后 → 没有持仓，拒绝并提示"如果实际是被指派，请先删除该到期作废"；日期早于到期日时，插入后作废会超过持仓或不再是整笔批次 → 拒绝，提示先删除该到期作废。用户先删除作废，再记被指派，再作废剩余。
- **删除被指派而之后有作废**：作废可能因此不再是整笔批次 → 拒绝，提示先删除该到期作废。
- 旧的 16:00 之后交易（FEAT-012 之前录入）：被指派不像作废那样覆盖全部持仓，不做专门的阻挡；只按重放检查。

### 持仓（期权持仓）新增的数据
- 每个持仓：**是否可以被指派**——空头 put 为是，**任何时刻**（到期前、到期日当天各时段包括"到期待确认"、17:30 之后、已过期，Q95）；多头、空头 call 为否（空头 call 由 FEAT-041 打开）。
- **可被指派的张数**及对应股数（当前 FIFO 的整批次累计张数，同平仓的"可平张数"）。
- **指派日期的默认值**和**最晚可选日期**：最晚 = 到期日与"今天（美东 16:00 之后）/ 昨天（16:00 之前）"中较早的一个；默认 = 最晚可选日期（通常就是到期日）。前端不自己算日期。
- 已有的"可以平仓""到期待确认""可以作废"口径不变。

### 查询的变化
- **期权交易列表（FEAT-002）**：被指派记录出现在列表中，时间 = 指派日期 16:00；方向筛选增加"被指派"；按 ID 查询返回被指派记录的全部字段（见操作 1 的返回）；不可修改、可删除；"有审计记录"恒为否。
- **已平仓（FEAT-006 / 040）**：被指派记录作为**期权**一行：方向"被指派"、空头、张数、开仓净额合计（每张平均）、平仓净额 `0.00`、已实现盈亏 `0.00`、被指派批次；另给出"权利金已计入股票成本"所需的数据（股数、股票成本）。计入笔数（Q97），合计不受影响（0.00）。方向筛选增加"被指派"（属于期权专用条件，Q90）。日期筛选按指派时间的美东日期。
- **盈亏汇总、首页（FEAT-008 / 040）**：被指派按指派时间归属日期 / 月份，计入期权笔数（Q97），金额 0.00；之后股票卖出的盈亏按卖出时间计入股票。
- **股票交易列表、股票持仓（FEAT-011）**：新类型"指派买入"；可按类型筛选；每条给出关联的被指派记录 ID、"可修改 / 可删除"为否；持仓批次和被卖出批次的来源类型可为"指派买入"。
- **资金（FEAT-007）**：新来源类型"被指派"。
- **审计（FEAT-005）**：删除被指派写审计（见操作 2）；审计记录页能看出是"被指派"。
- 所有查询和操作只针对当前账户（Q53）；用另一账户的 ID → "不存在"。

## 验收标准
现金汇总 = 总现金 / 冻结 / 可用。后端测试固定时钟（每条注明）。E2E 用真实时钟：把下面的日期换成相对运行当天美东日期 T 的日期（到期日用 T−3 等过去的日期；提前指派、Q94 用 T−1 / T），同 FEAT-012 的做法。以下标的都是虚构的。除第 8–10 条外都在默认账户。

**场景 P**：入金 D1 = 20,000.00（2026-11-02 10:00），按顺序录入：

| 编号 | 方向 | 合约 | 张数 | 净额 | 成交时间（美东） | 冻结 |
|------|------|------|------|------|-----------------|------|
| P1 | STO | XYZ 2026-11-20 45 P | 2 | 240.00 | 2026-11-03 10:00 | 9,000.00 |
| P2 | STO | XYZ 2026-11-20 45 P | 1 | 130.00 | 2026-11-05 10:00 | 4,500.00 |
| P3 | STO | QRTV 2026-12-18 30 P | 1 | 85.00 | 2026-11-06 10:00 | 3,000.00 |
| P4 | BTO | QRTV 2026-11-20 25 C | 1 | 40.00 | 2026-11-06 11:00 | — |
| P5 | STO | IXQZ 2026-11-20 8 C | 1 | 22.00 | 2026-11-06 12:00 | —（未冻结） |

现金汇总 **20,437.00 / 16,500.00 / 3,937.00**。2026-11-20 是星期五，2026-11-23 是星期一。

1. **持仓页按钮与时间窗（Q95）**
   **Given** 场景 P
   - 时钟 2026-11-17 10:00：XYZ 行、QRTV 30 P 行有 `平仓`、`被指派`；QRTV 25 C（多头）、IXQZ 8 C（空头 call）只有 `平仓`，没有 `被指派`。
   - 时钟 2026-11-20 16:30：XYZ 行显示"今天到期""到期待确认"，只有 `被指派`；IXQZ 8 C、QRTV 25 C 行没有任何按钮。
   - 时钟 2026-11-23 10:00：XYZ 行"已过期 3 天"，有 `作废`、`被指派`；QRTV 25 C、IXQZ 8 C 只有 `作废`。
   - 打开 XYZ 的"被指派"对话框（时钟 2026-11-23）：张数选项 `2 张（200 股）`、`3 张（300 股）`，默认 3 张；指派日期默认 `2026-11-20`，不能选 2026-11-21 及之后；指派费 `0.00`。
   - 直接请求被指派 IXQZ 8 C → 被拒绝"卖出 call 的被指派暂不支持（FEAT-041）"；QRTV 25 C（多头 call）→ 被拒绝"多头持仓不能被指派（主动行权见 FEAT-014）"（规则 2 先判断多头）。

2. **到期被指派全部 3 张：成本扣除权利金、现金、各页面显示（Q8、Q74）**
   **Given** 场景 P，时钟 2026-11-23 10:00
   **When** XYZ 被指派 3 张、日期 2026-11-20、指派费 0.00
   **Then** 结果：记在 `2026-11-20 16:00（美东）`（存 `2026-11-20T21:00:00Z`）、被指派批次 P1（2 张 +240.00）、P2（1 张 +130.00）、权利金 `370.00`、买入 300 股、买股金额 `13,500.00`、股票成本 **`13,130.00`**、每股 `43.7667`、现金变动 `−13,500.00`、冻结变动 `−13,500.00`、期权已实现盈亏 `0.00`。
   **And** 现金汇总 **6,937.00 / 3,000.00 / 3,937.00**（可用不变）。
   **And** 期权持仓没有 XYZ；股票持仓 XYZ 300 股、总成本 13,130.00、每股 43.7667，批次 `指派买入 2026-11-20 16:00`。
   **And** 资金流水新一条：`2026-11-20 16:00`、`被指派`、`−13,500.00`、冻结 `−13,500.00`、余额 `6,937.00`、说明 `被指派 3 张 XYZ 2026-11-20 45 P，买入 300 股 XYZ`。
   **And** 交易列表第一行：`2026-11-20 16:00`、`被指派`、`XYZ 2026-11-20 45 P`、`3`、净额 `0.00`、冻结 `−13,500.00`、小字 `买入 300 股 XYZ，现金 −13,500.00`；有"删除"，没有"修改""历史"。方向只选"被指派" → 只有这一条。
   **And** 股票页一行 `指派买入`、XYZ、300、`成本 13,130.00`、`每股 43.7667`、`来自被指派 #<ID>`；没有修改、删除、历史。
   **And** 已平仓页一行：期权、`被指派` / 空头、3、开仓 `+370.00`（每张 `+123.33`）、平仓 `0.00`、已实现盈亏 `0.00`（不着色）、小字 `权利金已计入股票成本（300 股 XYZ，成本 13,130.00）`；`共 1 笔平仓`、合计 `0.00`（Q97）。盈亏汇总 XYZ 1 笔、期权 `0.00`、股票 `—`、合计 `0.00`；首页总计 `0.00（1 笔）`。
   **And** 审计记录页没有新记录；不刷新页面以上各页都显示新数据。

3. **之后卖出股票：权利金体现在股票盈亏（FEAT-040）；同一时间按录入顺序**
   **Given** 第 2 条之后
   - **When** 卖出 XYZ 100 股，实收 4,400.00，时间 2026-11-20 15:00 **Then** 被拒绝"持股不足：2026-11-20 15:00 卖出 XYZ 100 股，当时持有 0 股"（股票 16:00 才到账）。

   **And** 已平仓页 2 行，股票卖出 `+23.33` 在上、被指派 `0.00` 在下，`共 2 笔`、合计 `+23.33`；盈亏汇总 XYZ 2 笔：期权 `0.00`、股票 `+23.33`、合计 `+23.33`。

4. **提前指派、指派费、整笔批次（Q73）、剩余作废（Q65）、日期规则（Q76、Q94）**
   **Given** 场景 P，时钟 2026-11-19 10:00
   - XYZ 被指派 1 张 → 被拒绝"必须一次被指派整笔开仓：最早一笔是 2 张，可为 2 张或 3 张"。
   - 日期 2026-11-21 → 被拒绝"指派日期不能晚于到期日（2026-11-20）"；日期 2026-11-19（今天，未到 16:00）→ 被拒绝"指派日期为今天时，美东 16:00 之后才能记录"；日期 2026-11-02 → 被拒绝"2026-11-02 16:00 时该合约（XYZ 2026-11-20 45 P）没有持仓可被指派"。

   - **When** 时钟 2026-11-23 10:00 作废 XYZ **Then** 作废 1 张（P2），已实现 `+130.00`；现金汇总 11,432.00 / 3,000.00 / 8,432.00；已平仓页 XYZ 两行：作废 `+130.00`（11-20 16:00）在上、被指派 `0.00`（11-18 16:00）在下。

5. **与到期作废的先后（FEAT-012）**（每项从场景 P 开始，时钟 2026-11-23 10:00）
   - **先指派后作废**：被指派 2 张（日期 2026-11-20）**Then** 成功（P1，股票成本 8,760.00）；再作废 XYZ **Then** 作废 1 张（P2）`+130.00`，两条记录都在 2026-11-20 16:00，交易列表中作废在上。**When** 删除被指派 **Then** 被拒绝"删除后该合约（XYZ 2026-11-20 45 P）在 2026-11-20 16:00 的到期作废 1 张将不是整笔批次（最早一笔是 2 张，可为 2 张或 3 张），请先删除该到期作废"。**When** 先删除作废、再删除被指派 **Then** 都成功，XYZ 恢复 3 张、现金汇总 20,437.00 / 16,500.00 / 3,937.00、股票 XYZ 消失。

6. **删除被指派、不可修改**

## 边界情况
- **提前指派**：日期早于到期日，剩下的批次照常为持仓（验收 4）；之后还可以平仓、再被指派或作废。
- **到期日当天的时间点**：16:00 前、16:00–17:30、17:30 后都可以记被指派（Q95，验收 1）；指派记在所填日期 16:00，不随点按钮的时刻变化。
- **指派日期为今天**：16:00 前不能选（Q94，验收 4）；补记过去的日期按 Q19 重放（Q76）。
- **周末 / 假日**：不检查交易日（FEAT-009）；日期填券商通知上的日期。
- **夏令时**：16:00 美东按当天时区换算（EST → 21:00Z，EDT → 20:00Z）。
- **一次被指派覆盖多个批次**：权利金、冻结按批次相加，股票成为**一个**批次（验收 2）。
- **部分被指派**：只能是最早的整批次（Q73，验收 4）；真实发生"一笔多张批次只被指派一部分"时录不进去——此时请告诉 PM，按 Q73 备注重新讨论。
- **被指派与作废**：同一批次不能两者都有；先指派后作废；已作废要先删除作废（验收 5）。
- **同一时间（16:00）的股票卖出**：在被指派之后录入时可以用到该批次（验收 3）。
- **已有同标的股票**：生成的批次按时间排进 FIFO，可能不是最早的批次。
- **修改/删除之前的交易**：按重放原则，权利金变化改变股票成本和之后卖出的盈亏（验收 7）。
- **指派费与可用现金**：可用为 0 时指派费 > 0 被拒（验收 8）。
- **multiplier ≠ 100、行权价 3 位小数**：买股金额向上取整到分，可用可能 +0.01（验收 9）。
- **股票成本 ≤ 0**：拒绝（只可能来自录错的开仓净额）。
- **权利金不进期权盈亏**：被指派当月的已实现盈亏里看不到这笔权利金，股票卖出时才体现（验收 2、3）。
- **空头 call、多头**：不能被指派（FEAT-041、FEAT-014）。
- **指数期权（现金结算）**：不支持（Q11）；系统不识别指数，请勿对指数期权使用"被指派"。
- **covered call 覆盖**：被指派得到的股票以后会被 FEAT-039 的覆盖检查计入；本需求不做覆盖检查。
- **拆股**：不在本需求（FEAT-028）。

## Out of Scope
- 卖出 call 被指派（FEAT-041）；主动行权（FEAT-014）；批量到期处理（FEAT-015）
- 拆分批次的部分指派（Q73）；不按 FIFO 选择批次
- 修改被指派记录（只能删除后重记）；单独修改/删除生成的股票记录
- 现金结算（指数期权，Q11）
- 判断期权是否价内、自动生成被指派（需要行情或券商数据）
- Wheel 视图、调整后成本展示（FEAT-026）；covered call 覆盖检查（FEAT-039）
- 全部账户合并查看（FEAT-035）；任何券商接入
