## 背景 / 用户故事
作为一个在 2 个账户里做期权的交易者，我现在要来回切换账户才能知道"我一共有多少现金、多少持仓、总共赚了多少"。我想在账户切换器里选"全部账户"，在首页、持仓页、资金汇总、盈亏汇总上一次看到两个账户合在一起的数字，并且每行能看出属于哪个账户；在这个模式下不能录入、修改、删除任何东西，避免记错账户。

**拆分（PM）：** 合并查看涉及全部页面，超过一次会话。本需求做框架和最常用的 4 个视图；其余页面在 **FEAT-046**（交易列表、股票交易、已平仓、资金流水）和 **FEAT-047**（策略页、组合 Greeks 汇总）。在它们上线前，这些页面在"全部账户"下显示占位提示（规则 7）。

## 规则
1. **切换器**：账户下拉在各账户之上加一项 `全部账户`。选中后各页面醒目位置显示 `当前：全部账户（只读）`。只有一个账户时不显示该项（Q220）。与单个账户一样记住上次选择（Q219）。
2. **范围**：`全部账户` = 当时存在的全部账户；新增账户后自动包含。
3. **行**：同一合约 / 同一标的的股票在不同账户里**分行显示，不合并**（Q215）；每行首列 `账户`（账户名称），只在全部账户模式下出现（Q214）。排序沿用各页面原规则，原规则相同时按账户 ID 升序（Q214）。不另设账户筛选，看单个账户用切换器（Q214）。
4. **合计**：所有合计由后端给出，等于各账户对应数字之和（Q216）：现金三项、冻结合计、持仓个数（按行数）、到期个数、已实现盈亏、市值、未实现盈亏。**例外（Q227）**：首页 `股票持仓 N 个标的` 和持仓页股票卡 `共 N 个标的` 的 N 按**不同标的**跨账户去重计数（甲有 QRTV、IXQZ，乙有 QRTV → N = 2）；股票行仍按账户分行（规则 3）。被 Q160 排除的行不计入，提示个数也是全部账户合计。
5. **只读**（Q217）：所有写操作的按钮和入口**隐藏**（不是禁用）：录入交易 / 股票、入金 / 出金、修改、删除、平仓、作废、被指派、行权、批量作废、调整到期日。页面顶部一行提示：`全部账户（只读）：录入、修改、删除请先选择一个账户`。直接打开录入页（`/trades/new`、`/stocks/new`）时不显示表单，显示 `录入需要选择一个账户` 和每个账户一个按钮，点击即切换到该账户并显示表单。后端拒绝任何不指明单个账户的写请求。
6. **不受影响的操作**：行情"立即刷新"和手动覆盖 mark（全系统一份行情，不属于账户，Q218）、账户页（新增、改名、切换）照常可用。
7. **尚未支持的页面**（Q223）：交易列表、股票交易、已平仓、策略、审计记录页，以及资金页的流水部分，在全部账户模式下显示 `此页暂不支持全部账户，请选择一个账户查看` 和每个账户一个切换按钮；持仓页的组合 Greeks 汇总（FEAT-019）在开关打开时显示灰字 `组合 Greeks 汇总暂只支持单个账户`（Q224）。审计页按 Q225。

## 需要的数据和操作（给 backend）
后端如何提供（新接口或现有接口加"全部账户"范围）由 backend-dev 在契约阶段定（Q226）。全部账户模式下需要：
- **首页概览**（FEAT-008 / 040 的全部字段）：全部账户合计（规则 4）。
- **现金汇总**：每个账户一行（账户 ID、名称、总现金、冻结、可用）+ 合计行。
- **期权持仓、股票持仓**：全部账户的行，字段与单账户相同（批次、DTE、剩余交易日、冻结、覆盖标签、到期状态、行情、市值、未实现、每行 Greeks 等），每行加账户 ID 和名称；排序按规则 3。顶部持仓个数、冻结合计按规则 4。
- **未实现合计**（FEAT-017 规则 7 的 6 个数字 + 未计入个数）：全部账户合计。
- **盈亏汇总**（FEAT-008 / 040，含日期范围、期权 / 股票拆分）：同一标的、同一月份跨账户合并为一行（Q222），合计行。
- **临时休市提醒**（FEAT-042）：每个临时休市日的受影响持仓总数，以及按账户的个数（Q221）。
- **写操作**：任何写请求不指明单个账户 → 明确的错误，不改动数据。
- 单账户的接口与行为不变。

## 页面与交互（给 frontend）
- **切换器**：规则 1；切换到 / 离开全部账户时当前页面立即重新显示，不刷新；地址栏筛选参数保留。
- **首页**：卡片与单账户相同，数字为合计；`录入交易` 入口隐藏；到期个数链接照常到持仓页过滤（全部账户）；本月已实现的 `/closed` 链接照常跳转（落在规则 7 的占位，FEAT-046 后显示合并结果）。
- **临时休市提醒**（首页、持仓页顶部）：一行写合计个数和按账户分列，如 `…你有 2 个持仓在该日到期（甲账户 1 个、乙账户 1 个）…`；`去调整` 改为每个有受影响持仓的账户一个链接 `切换到 <账户> 去调整`：切换到该账户、打开持仓页并定位到该账户第一个受影响行（同 FEAT-042）（Q221）。
- **持仓页**：期权表、股票表加 `账户` 首列（规则 3）；顶部持仓个数 / 冻结合计、未实现合计行为合计（规则 4）；到期过滤照常（合计不随过滤，Q158）；行上没有任何写操作按钮（规则 5）；批次展开、行情状态、每行 Greeks 开关照常。
- **资金页**：汇总区改为每账户一行 + 合计行（`账户 / 总现金 / 冻结 / 可用`）；入金 / 出金表单隐藏；流水区按规则 7 占位。
- **盈亏汇总页**：按标的、按月两表与合计为跨账户合并的数字（不加账户列）；日期范围筛选照常。
- **切回单个账户**：所有页面恢复为原来的单账户样子（无账户列、按钮回来）。

## 验收标准
**场景 S**（所有条目共用；今天 2026-11-23 星期一 10:00 美东，行情 10:00 拉取成功；账户名、标的均为虚构；multiplier 100）
- **甲账户**（ID 1）：入金 50,000.00；转入 IXQZ 100 股、总成本 5,880.00（现价 61.10）；A1 = STO 1 张 QRTV 2026-12-18 50P、净额 118.70（mark 1.25）；STO 1 张 QRTV 2026-12-18 48P 净额 100.00、11-10 BTC 净额 40.00（已实现 +60.00）；A4 = STO 1 张 IXQZ 2026-11-27 65C、净额 84.35（mark 0.85，已覆盖 100 股）。
- **乙账户**（ID 2）：入金 20,000.00；10-15 BTO 1 张 QRTV 2026-12-18 55C 净额 50.00、10-20 STC 净额 80.00（已实现 +30.00）；B3 = STO 1 张 QRTV 2026-12-18 50P、净额 120.00（与 A1 同一合约）；B4 = STO 1 张 QRTV 2026-11-20 45P、净额 60.00（已过期 3 天，未处理）。
- 单账户现金：甲 50,263.05 / 5,000.00 / 45,263.05；乙 20,210.00 / 9,500.00 / 10,710.00。

1. **切换器**：**When** 在切换器选 `全部账户` **Then** 显示 `当前：全部账户（只读）` 和只读提示；刷新浏览器后仍是全部账户（Q219）；**When** 切到甲账户 **Then** 持仓页只有 A4、A1 两行，没有 `账户` 列，平仓 / 作废等按钮恢复。
2. **首页**：**Given** 全部账户 **Then** 现金 `70,473.05 / 14,500.00 / 55,973.05`；已实现 `总计 +90.00（2 笔）`、`本月（2026-11）+60.00（1 笔）`；`期权持仓 4 个`、冻结合计 `14,500.00`、`7 天内到期 1 个`、`已过期未处理 1 个`、`股票持仓 1 个标的`；没有 `录入交易` 入口。
3. **资金页**：**Given** 全部账户 **Then** 汇总表 `甲账户 50,263.05 / 5,000.00 / 45,263.05`、`乙账户 20,210.00 / 9,500.00 / 10,710.00`、`合计 70,473.05 / 14,500.00 / 55,973.05`；没有入金 / 出金表单；流水区显示占位提示（规则 7）。
4. **持仓页期权行**：**Given** 全部账户 **Then** 期权表 4 行依次为 `乙账户` B4（`已过期 3 天`，冻结 4,500.00）、`甲账户` A4（DTE 4，`已覆盖 100 股`）、`甲账户` A1（净额 118.70，冻结 5,000.00）、`乙账户` B3（净额 120.00，冻结 5,000.00）；A1、B3 是同一合约的两行；顶部 `持仓 4 个`、冻结合计 `14,500.00`。
5. **股票与未实现合计**：**Given** 全部账户 **Then** 股票表一行 `甲账户` IXQZ 100 股、市值 `+6,110.00`、未实现 `+230.00`；A1 未实现 `−6.30`、B3 `−5.00`、A4 `−0.65`、B4 `已到期，待处理`；合计行 `期权 市值 −335.00 未实现 −11.95 ｜ 股票 市值 +6,110.00 未实现 +230.00 ｜ 合计 市值 +5,775.00 未实现 +218.05`，提示 `1 个持仓已到期待处理，未计入`。**When**（Q227 补充）乙账户再转入 IXQZ 50 股 **Then** 股票表两行（`甲账户` IXQZ、`乙账户` IXQZ），股票卡 `共 1 个标的`、首页 `股票持仓 1 个标的`；切到乙账户时为 `1 个标的`。
6. **到期过滤与首页链接**：**Given** 全部账户 **When** 在首页点 `7 天内到期 1 个` **Then** 持仓页 `?expiry=7` 只有 `甲账户` A4；**When** 选 `已过期未处理` **Then** 只有 `乙账户` B4；两种过滤下冻结合计仍为 `14,500.00`、未实现合计不变。
7. **盈亏汇总**：**Given** 全部账户 **Then** 按标的 `QRTV 2 笔 +90.00`（期权 +90.00、股票 0.00）；按月 `2026-11 1 笔 +60.00`、`2026-10 1 笔 +30.00`；合计 `+90.00`。**When** 日期范围 2026-11-01 ~ 2026-11-30 **Then** `QRTV 1 笔 +60.00`。**When** 切到乙账户 **Then** `QRTV 1 笔 +30.00`。
8. **临时休市提醒**：**Given** 场景 S 另有临时休市记录 2026-12-18（Test Closure）**When** 全部账户打开首页和持仓页 **Then** 顶部 `2026-12-18 临时休市（Test Closure），你有 2 个持仓在该日到期（甲账户 1 个、乙账户 1 个）…`，带 `切换到 甲账户 去调整`、`切换到 乙账户 去调整`；**When** 点后者 **Then** 当前账户变为乙账户，持仓页定位到 B3。
9. **只读**：**Given** 全部账户 **Then** 持仓页任何行都没有平仓、作废、被指派、行权、调整到期日按钮，没有 `批量作废`；资金页、首页没有写入口。**When** 打开 `/trades/new` **Then** 不显示表单，显示 `录入需要选择一个账户` 和 `甲账户`、`乙账户` 按钮；点 `乙账户` → 当前账户为乙账户，显示录入表单。**When**（后端）不指明单个账户发入金 100.00 **Then** 返回错误，两个账户现金不变。
10. **尚未支持的页面**：**Given** 全部账户 **When** 打开交易列表、股票交易、已平仓、策略、审计记录页 **Then** 都显示 `此页暂不支持全部账户，请选择一个账户查看` 和两个账户按钮；持仓页打开"显示 Greeks"时，组合 Greeks 汇总位置显示 `组合 Greeks 汇总暂只支持单个账户`，每行 Greeks 照常显示。

## 边界情况
- **同一合约在两个账户一空一多**：两行，各自方向和数字（Q53）；合计按规则 4 直接相加。
- **只有一个账户**：没有 `全部账户` 项；若浏览器记住了全部账户但只剩一个账户，按 Q55 选 ID 最小的账户。
- **新增账户**：全部账户模式下立即包含新账户（全 0 不影响合计；资金汇总表多一行 0.00）。
- **全部账户下打开着的对话框**：不会出现（没有写入口）；从单账户切到全部账户时，打开着的对话框按 FEAT-033 关闭。
- **行情**：同一合约跨账户共用 mark（FEAT-017 边界情况）；手动覆盖影响所有账户的行（规则 6）。
- **地址栏链接**：不带账户（Q55），在全部账户模式下按全部账户解释；链接到尚未支持的页面时落在占位（规则 7）。
- **到期日当天、周末 / 假日**：沿用各页面单账户规则，不变。拆股：不在本需求。

## Out of Scope
- 交易列表、股票交易、已平仓、资金流水的合并（FEAT-046）；策略页、组合 Greeks 汇总的合并（FEAT-047）；审计页（Q225）
- 账户间转账（FEAT-036）、归档（FEAT-037）
- 全部账户模式下的任何写操作；按账户的小计（持仓页、盈亏汇总只给全部合计）
- 新的计算口径（跨账户 FIFO、跨账户担保 / 覆盖）——都不存在，各账户独立
