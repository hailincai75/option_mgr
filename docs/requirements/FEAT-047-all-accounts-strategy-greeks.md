## 背景 / 用户故事
作为一个在 2 个账户里做期权的交易者，FEAT-035 / 046 之后"全部账户"下只剩策略页是占位，持仓页的组合 Greeks 汇总也只写 `组合 Greeks 汇总暂只支持单个账户`。我想在全部账户下也能看到每个标的的持仓和盈亏卡片，以及两个账户加在一起每个标的的 Delta 美元敞口、Theta、Vega，知道我整体在某只股票上的风险有多大。

本需求是 FEAT-035 拆分的最后一部分。

## 已定的口径
- Q53：合并不改变任何计算，单账户的数字不变。Q55：链接不带账户，按当前账户（含全部账户）解释。
- Q183：策略页按 账户 + 标的 自动分组。Q184–Q187 卡片内容；Q195–Q203 卡片摘要（已实现全部时间、净权利金、无全部标的合计行、不显示 Greeks、标的升序）。
- Q174–Q182：组合 Greeks 的分组、排除、全组合只加美元敞口 / Theta / Vega、取整（Q181）。Q160 / Q172 未计入与缺值提示。
- Q214 账户列 / 同序按账户 ID；Q215 不合并行；Q216 合计相加；Q217 只读；Q218 行情操作可用；Q222 盈亏汇总按标的跨账户合并；Q223 占位；Q226 实现方式由 backend-dev 定；Q231 "切换到该行账户再打开"的做法。
- Q224：策略卡片按 账户 + 标的 分开，Greeks 按标的跨账户合并。Q233：合并美元敞口 = 合并净 Delta × 标的价再取整到分。Q234：合并行不显示各账户构成。Q235：卡片 `已实现` 链接先切到该卡片账户再打开已平仓。

## 规则
1. **范围**：全部账户模式下策略页、持仓页 `按标的 Greeks 汇总` 区块显示合并结果，不再显示 FEAT-035 规则 7 的占位 / 灰字。审计页仍按 Q225。
2. **策略卡片**（Q224）：每个 账户 + 标的 一张卡片，同一标的在两个账户里是两张卡片。标题以账户名开头：`甲账户 · ZZA  期权 1 个持仓 · 股票 100 股`。卡片内容、行上数字、摘要行（已实现、未实现、合计、市值、净权利金、未计入提示）与在该账户下看到的完全相同（Q53）。
3. **卡片排序**：标的字母升序，同一标的按账户 ID 升序（Q203 + Q214）。没有全部标的合计行（Q201）。
4. **卡片一致性**：全部卡片的市值、未实现之和及未计入个数 = 全部账户持仓页合计行（FEAT-035）；同一标的各卡片已实现之和 = 全部账户盈亏汇总（不带日期）该标的一行（Q222）。
5. **Greeks 按标的合并**（Q224、Q234）：全部账户中有期权或股票持仓的每个标的一行（不按账户分行、不加账户列、不显示各账户构成）。期权 Delta / Gamma / Theta / Vega = 全部账户该标的可计算期权行的持仓值之和；股票 Delta = 全部账户持股数之和；净 Delta、美元敞口、排除与缺值规则同 FEAT-019 规则 4–6，未计入个数为全部账户合计。美元敞口的取整口径见 Q233。
6. **全组合**：各合并行的美元敞口、Theta、Vega 分别相加（FEAT-019 规则 7、8）；提示个数为全部账户合计。
7. **只读与链接**：策略页本来没有写按钮；合约 → 交易列表、标的 → 股票交易的链接停留在全部账户并显示合并结果（同 FEAT-046 规则 9）。卡片 `已实现` 数字的链接见 Q235。
8. **不变**：单账户下策略页、Greeks 汇总的行为和数字不变；写请求不指明单个账户仍被拒绝。

## 需要的数据和操作（给 backend）
全部账户模式下（实现方式见 Q226）：
- **按标的盈亏摘要**（FEAT-023 的数据）：每个 账户 + 标的 一组，字段与单账户相同，另加账户 ID 和名称；排序按规则 3。卡片里的持仓行已由 FEAT-035 的全部账户持仓数据提供（每行带账户）。
- **组合 Greeks 汇总**（FEAT-019 的数据）：按标的合并的行（规则 5）和全组合（规则 6），字段与单账户相同，不带账户。
- 只读、读取时计算，不新增存储；单账户接口与行为不变。

## 页面与交互（给 frontend）
- **策略页**：去掉占位；顶部灰字中 `当前账户` 改为 `全部账户（每个账户的每个标的一张卡片）`，其余文字同 FEAT-023；卡片按规则 2、3，标题首部显示账户名；行和摘要的显示同 FEAT-023；数字全部取后端值。空状态 `暂无持仓`。
- **持仓页 Greeks 汇总**：`显示 Greeks` 打开时显示 `按标的 Greeks 汇总` 区块（不再是灰字），列与单账户相同、无账户列；区块说明中 `当前账户` 改为 `全部账户`。开关关闭时不显示。
- **刷新**：在单账户写操作、行情刷新、设置 / 清除手动值后切到全部账户，无需手动刷新即为最新数据（沿用 FEAT-019 / 023 的刷新）。切回单账户恢复原样子。

## 边界情况
- **标的只在一个账户**：一张卡片；Greeks 行即该账户的值（如 ZZB 的期权部分只来自甲）。
- **一个账户有股票、另一个账户卖 call**：Greeks 合并后股票 Delta 与 call 相抵，但不表示被覆盖——覆盖检查仍只看同一账户（FEAT-039），卡片和持仓行的覆盖标签不变。
- **合并后净 Delta 为 0**：美元敞口 `0.00`（FEAT-019）。某标的在所有账户里都只剩已到期待处理期权：同 FEAT-019 边界（期权部分 `—`）。
- **手动 mark**：不影响 Greeks 和美元敞口（Q170），只影响卡片市值 / 未实现。
- **新增 / 改名账户**：自动包含，卡片标题显示新名称。
- **到期日当天、周末 / 假日、拆股**：沿用单账户规则；拆股见 FEAT-028。
