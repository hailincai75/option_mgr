## 背景 / 用户故事
作为一个期权交易者，首页告诉我"7 天内到期 N 个""已过期未处理 N 个"，但持仓页把所有持仓列在一起，我得自己去找。我想要在持仓页选一个到期过滤，**只看到**符合条件的持仓（不是排序或高亮），并在同一行上直接用已有的平仓 / 作废 / 被指派处理掉；首页的两个数字点一下就进入对应的过滤结果。

## 已定的口径（只引用）
- Q34：DTE = 到期日 − 今天（美东日历天）；0 为"今天到期"，负数为"已过期 N 天"并标红。
- Q35：持仓排序（到期日升序 → 标的 → 行权价 → Call 在 Put 前）。
- Q48：首页"7 天内到期"= 0 ≤ DTE ≤ 7，"已过期未处理"= DTE < 0。
- Q10、Q83：到期日 16:00 停止交易，16:00–17:30 "到期待确认"，17:30 起可作废。Q95：被指派按钮。
- Q53：只看当前账户。
- Q80：到期范围提供 7 / 14 / 30 天（改为持仓页过滤选项，不做新页面）。
- Q105：首页两个到期个数链接到持仓页对应的过滤。
- Q108：个数为 0 时仍是链接。Q109：过滤时隐藏股票部分并显示说明。Q110：冻结合计仍为全账户，另加"显示 M / N 个持仓"。

## 规则
1. **过滤选项**（只作用于期权持仓表）：

   | 选项 | 地址栏 | 条件 |
   |------|--------|------|
   | 全部（默认） | 无参数 | 不过滤 |
   | 已过期未处理 | `?expiry=expired` | DTE < 0 |
   | 今天到期 | `?expiry=today` | DTE = 0 |
   | 7 天内 | `?expiry=7` | 0 ≤ DTE ≤ 7 |
   | 14 天内 | `?expiry=14` | 0 ≤ DTE ≤ 14 |
   | 30 天内 | `?expiry=30` | 0 ≤ DTE ≤ 30 |

   "N 天内"含今天、含第 N 天；"7 天内"的个数 = 首页"7 天内到期"，"已过期未处理"的个数 = 首页"已过期未处理"（Q48）。
2. **到期待确认**（到期日 16:00–17:30，FEAT-012）以及 17:30 之后尚未处理的当天持仓：DTE = 0，属于"今天到期"和各"N 天内"，不属于"已过期未处理"；到期日次日（美东）起才进入"已过期未处理"。
3. **真正过滤**：选了"全部"以外的选项时，表里只有符合条件的行，其它行不显示；顺序仍按 Q35（最早到期在上）。DTE 取后端已有值，前端只比较、不计算日期。
4. **地址栏**：过滤状态写在地址栏，刷新、复制链接后保持；`expiry` 是其它值（如 `10`、`abc`）时按"全部"显示。
5. **顶部**：沿用"截至 YYYY-MM-DD（美东）"、持仓个数、冻结现金合计（全账户，不随过滤变化，Q110）；过滤时另显示 `显示 M / N 个持仓`（M = 表中行数）。
6. **空结果**：过滤后没有行时，表格位置显示对应提示：`没有已过期未处理的持仓`、`没有今天到期的持仓`、`没有 7 天内到期的持仓`（14、30 同理）。账户没有任何期权持仓时沿用持仓页原有空状态。
7. **按钮不变**：行上的平仓 / 作废 / 被指派按钮、对话框、拒绝提示完全沿用现有行为。操作成功后列表无需手动刷新即更新，不再符合过滤条件的持仓（被处理掉、或剩余部分不再符合）从表中消失；过滤选项保持不变。
8. **首页链接**（Q105）：首页 `7 天内到期 N 个` → 持仓页 `?expiry=7`；`已过期未处理 N 个` → `?expiry=expired`。N = 0 时仍是链接（Q108）。
9. **股票持仓**：不参与过滤；选了"全部"以外的选项时隐藏股票部分，显示一行 `股票持仓不参与到期过滤，选择'全部'查看`（Q109）。

## 验收标准
后端无改动；以下由前端测试（mock 数据）和 E2E 覆盖。E2E 用真实时钟，场景 R 中 2026-11-18 换为运行当天美东日期 T，其它日期按同样天数差。标的都是虚构的。

**场景 R**（默认账户）：入金 30,000.00（2026-11-02 10:00），录入：

| 编号 | 方向 | 合约 | 张数 | 净额 | 成交（美东） |
|------|------|------|------|------|-------------|
| R1 | STO | XYZ 2026-11-13 40 P | 1 | 95.00 | 2026-11-03 10:00 |
| R2 | BTO | QRTV 2026-11-13 30 C | 2 | 120.00 | 2026-11-03 11:00 |
| R3 | STO | XYZ 2026-11-18 42 P | 2 | 180.00 | 2026-11-04 10:00 |
| R4 | BTO | QRTV 2026-11-20 25 P | 1 | 45.00 | 2026-11-05 10:00 |
| R5 | STO | XYZ 2026-11-25 38 P | 1 | 70.00 | 2026-11-06 10:00 |
| R6 | STO | XYZ 2026-11-27 35 P | 1 | 60.00 | 2026-11-09 10:00 |
| R7 | BTO | QRTV 2026-12-18 30 C | 1 | 210.00 | 2026-11-10 10:00 |
| R8 | BTO | QRTV 2027-01-15 30 C | 1 | 150.00 | 2026-11-10 11:00 |

时钟 2026-11-18 10:00（周三）时 DTE：R1、R2 −5；R3 0；R4 2；R5 7；R6 9；R7 30；R8 58。持仓 8 个，冻结合计 19,700.00。

1. **默认"全部"不变**
   **Given** 场景 R，时钟 2026-11-18 10:00 **When** 打开持仓页（无参数）**Then** 过滤显示"全部"，8 行，顺序 R2、R1、R3、R4、R5、R6、R7、R8，顶部 `共 8 个持仓`、`冻结现金合计 19,700.00`，没有 `显示 M / N` 字样；与 FEAT-003 原有显示一致。

2. **已过期未处理、今天到期**
   **Given** 第 1 条 **When** 选"已过期未处理" **Then** 地址栏 `?expiry=expired`；只有 2 行：`QRTV 2026-11-13 30 C`、`XYZ 2026-11-13 40 P`，都红色"已过期 5 天"；顶部 `显示 2 / 8 个持仓`，冻结合计仍 19,700.00。**When** 刷新 **Then** 仍是这 2 行。
   **When** 选"今天到期" **Then** `?expiry=today`，只有 R3（"今天到期"），`显示 1 / 8 个持仓`。

3. **7 / 14 / 30 天内与非法参数**
   **Given** 场景 R，时钟 2026-11-18 10:00
   - `?expiry=7` → R3、R4、R5（3 行，等于首页 `7 天内到期 3 个`）；
   - `?expiry=14` → R3、R4、R5、R6（4 行）；
   - `?expiry=30` → R3–R7（5 行，DTE 30 含在内）；R8 在三者中都不出现；
   - `?expiry=10` → 按"全部"显示，8 行，过滤显示"全部"。

4. **到期待确认的归类**
   **Given** 场景 R，时钟 2026-11-18 16:30 **When** 选"今天到期" **Then** 只有 R3，显示"到期待确认"，只有"被指派"按钮；**When** 选"已过期未处理" **Then** 只有 R2、R1（不含 R3）。
   **Given** 时钟 2026-11-18 17:45 **Then** R3 仍在"今天到期"，按钮"作废""被指派"。
   **Given** 时钟 2026-11-19 09:00 **When** 选"已过期未处理" **Then** R2、R1、R3（R3"已过期 1 天"），首页 `已过期未处理 3 个`。

5. **过滤状态下操作，行自动消失**
   **Given** 场景 R，时钟 2026-11-18 17:30，过滤"已过期未处理" **When** 在 R1 行作废并确认 **Then** 结果同 FEAT-012（已实现盈亏 `+95.00`、冻结变动 `−4,000.00`）；关闭后不刷新，表中只剩 R2，`显示 1 / 7 个持仓`，冻结合计 15,700.00，过滤仍是"已过期未处理"。
   **When** 切到"今天到期"，在 R3 行"被指派"记 2 张、指派日期 2026-11-18 **Then** 成功后表中显示 `没有今天到期的持仓`。
   **When** 切到"7 天内"，在 R4 行平仓 STC 1 张、净额 20.00、成交 2026-11-18 11:00 **Then** 成功后只剩 R5。

6. **空结果提示**
   **Given** 新账户：入金 1,000.00（2026-11-02 10:00），BTO 1 张 QRTV 2027-01-15 30 C，净额 150.00（2026-11-10 10:00）；时钟 2026-11-18 10:00
   **When** 依次选"已过期未处理""今天到期""7 天内""30 天内" **Then** 分别显示 `没有已过期未处理的持仓`、`没有今天到期的持仓`、`没有 7 天内到期的持仓`、`没有 30 天内到期的持仓`，顶部 `显示 0 / 1 个持仓`；选"全部" **Then** 1 行。

7. **首页链接（Q105、Q108）**
   **Given** 场景 R，时钟 2026-11-18 10:00 **When** 在首页点 `已过期未处理 2 个` **Then** 进入 `/positions?expiry=expired`，内容同第 2 条；**When** 点 `7 天内到期 3 个` **Then** 进入 `?expiry=7`，R3、R4、R5。
   **Given** 第 6 条的新账户 **Then** 首页 `7 天内到期 0 个`、`已过期未处理 0 个` 仍是链接（Q108），点击进入对应空结果（第 6 条提示）。

8. **周末与按账户隔离**
   **Given** 场景 R，时钟 2026-11-21 10:00（周六）**When** `?expiry=expired` **Then** R2、R1、R3、R4（R4"已过期 1 天"），等于首页 `已过期未处理 4 个`；`?expiry=7` **Then** R5（DTE 4）、R6（DTE 6）。
   **Given** 账户"小账户"：入金 5,000.00（2026-11-02 10:00）、STO 1 张 XYZ 2026-11-20 45 P，净额 100.00（2026-11-04 10:00）；时钟 2026-11-18 10:00 **When** 在"小账户"打开 `?expiry=7` **Then** 只有 `XYZ 2026-11-20 45 P`，`显示 1 / 1 个持仓`；默认账户的 `?expiry=7` 仍是 R3、R4、R5。

## 边界情况
- **N 天内的边界**：DTE = 0 和 DTE = N 都包含（验收 3）。
- **到期日当天 16:00 后**：仍是"今天到期"，次日才算已过期（规则 2，验收 4）。
- **周末 / 假日**：按日历天（Q34），不判断交易日（FEAT-009）（验收 8）。
- **同一到期日多个合约**：都出现，按 Q35（验收 2）。
- **作废 / 被指派后补录了较晚的同合约批次**：该持仓重新出现，按 DTE 归入相应过滤（FEAT-012 Q65）。
- **操作被拒**：原因在已有对话框内显示，表不变。
- **非法参数**：按"全部"（验收 3）。
