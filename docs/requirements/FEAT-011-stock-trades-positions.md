## 背景 / 用户故事
作为一个期权交易者，我卖 put 被指派后会持有股票，再在股票上卖 covered call；有时也自己买卖股票。我想要在系统里记录股票的买入、卖出，以及系统上线前就已经持有的股票（期初持仓），看到每个标的持有多少股、总成本和每股平均成本，每次卖出按 FIFO 算出已实现盈亏；买卖股票的现金进入资金账户，和期权共用同一个现金余额。录错了可以修改或删除，留审计记录。

这是被指派（FEAT-013）、行权（FEAT-014）、covered call 覆盖检查（FEAT-039）的前提。本需求只做股票**记账**，不做覆盖检查、不锁定股票。

## 已定的口径
来自 backlog Open Questions，本需求新定的：
- **Q2 可以直接录入股票买入/卖出**（不只是指派/行权自动生成）。
- **Q67 只记股数 + 含手续费的净额**：买入 = 实付（含手续费），卖出 = 实收（扣手续费后）。不记每股成交价、不单独记手续费。每股价格 = 净额 ÷ 股数，只用于显示（精度见 Q88）。例：买入 200 股，实付 1,500.00 → 每股 7.5000。
- **Q68 买入不能超过可用现金**：买入实付 ≤ 成交时点的可用现金；补录、修改、删除按 Q19 重放，任一时点总现金、可用现金都不能为负。不支持融资。
- **Q15 不能卖空**：卖出股数 ≤ 同一账户在卖出时点持有的该标的股数；补录、修改、删除后任一时点持股都不能为负。
- **Q69 股票允许部分卖出一笔批次**（与期权的 Q21 不同）：按 FIFO，从最早的批次开始扣；卖出一笔批次的一部分时，这部分的成本 = 批次成本 × 卖出股数 ÷ 批次股数，**四舍五入到分**，剩下的成本留在批次里；批次最后一次卖完时用剩余成本，所以批次的成本加起来不会差一分。例：一笔 300 股、成本 1,000.00，卖出 100 股实收 400.00 → 卖出部分成本 333.33，已实现盈亏 +66.67；剩 200 股、成本 666.67。（部分卖出之后再部分卖出，按批次的剩余成本、剩余股数分摊，见 Q87。）
- **Q70 股数只能是 ≥ 1 的整数**，不支持碎股。
- **Q71 股票转入（期初持仓）**：填标的、股数、总成本、日期，**不影响现金**；之后可以正常卖出，以后也可以被 covered call 指派交出（FEAT-013）。例：转入 IXQZ 100 股，总成本 750.00，日期 2026-10-01 → 股票持仓 100 股，现金不变。
- **Q72 股票已实现盈亏与期权合并显示**：拆到 FEAT-040（见上）。
- **Q86 转入记在该日美东 00:00**（当天开始）：当天任何时刻的卖出都能用到它，同一天的买入排在它后面。
- **Q87 再次部分卖出按剩余值分摊**：这部分成本 = 批次剩余成本 × 卖出股数 ÷ 批次剩余股数，四舍五入到分；批次最后卖完时取剩余成本。
- **Q88 每股价格、每股平均成本显示 4 位小数**（四舍五入，只用于显示，成本和盈亏仍按分）；**股数 ≤ 10,000,000**。
- **Q61 提示文字**（已确认）：录入交易页 STO call 提示的最后一句改为"covered call 覆盖检查（FEAT-039）上线后将自动检查"。

沿用的口径：
- 净额、总成本 > 0，最多 2 位小数，上限与 Q29 净额相同（≤ 9,999,999,999,999.99）；用户只填正数，类型决定现金方向（Q17、Q29）
- 标的：去首尾空格、转大写，1–10 位字母/数字/点（Q25），与期权的标的规则完全相同；同一标的的期权和股票用同一个写法（如 `IXQZ`、`BRK.B`）
- 时间按美东录入、存 UTC，默认当前时间，不得晚于当前时间（Q14、FEAT-001）
- 按 `(时间, 录入顺序)` 重放：同一时间的记录（入金/出金、期权交易、到期作废、股票记录）按录入顺序排；修改后的记录保留原来的录入顺序（Q19、FEAT-005）
- 修改/删除写审计，新增不审计；改动的字段、修改前后完整内容；"历史"入口只对有审计记录的行显示——记录上存"有审计记录"标记，修改时置上（Q12、Q44、M1.5 小改动）
- 合约/方向录错请删除后重录（Q43）：股票记录的**标的和类型不能改**
- 所有规则按账户独立（Q53）；账户不能改（Q54）
- 数据库迁移前自动备份（Q60）
- 所有金额、成本、盈亏、持股、每股价格由后端计算，前端只显示

**不适用于股票的规则**：
- 期权的到期时间限制（Q36、Q83 的"不晚于到期日美东 16:00"）不适用——股票没有到期日。股票买卖只要求时间不晚于当前；不检查是否交易日、是否交易时段（交易日历在 FEAT-009）。
- 期权的整笔平仓（Q21）、多空互斥（Q7）、multiplier（Q23）不适用于股票。
- 股票不冻结现金，也不被锁定（covered call 锁定在 FEAT-039）。

## 需要的数据和操作（给 backend）

### 股票记录
一条股票记录是以下 3 种之一：**买入**、**卖出**、**转入**（期初持仓）。

| 数据 | 规则 |
|------|------|
| 所属账户 | 当前账户（Q53），不能改 |
| 类型 | 买入 / 卖出 / 转入；不能改 |
| 标的 | 必填，规则同 Q25（去首尾空格、转大写，1–10 位字母/数字/点）；不能改 |
| 股数 | 必填，整数，1 ≤ 股数 ≤ 10,000,000（Q70、Q88） |
| 金额 | 必填，> 0，最多 2 位小数，≤ 9,999,999,999,999.99（Q17、Q29）。买入 = 实付（含手续费）；卖出 = 实收（扣手续费）；转入 = 总成本 |
| 时间 | 买入、卖出：美东日期 + 时刻，存 UTC，不得晚于当前时间。转入：只填美东日期，不得晚于今天（美东），记在该日美东 00:00（Q86），存 UTC（例：2026-10-01 00:00 美东（夏令时）= `2026-10-01T04:00:00Z`；2026-12-01 00:00 美东 = `2026-12-01T05:00:00Z`） |
| 备注 | 可选，≤ 500 字符 |
| 录入顺序 | 与入金/出金、期权交易共用"同一时间按录入顺序"的排序 |
| 有审计记录 | 新增时为否；第一次修改成功时置为是（同期权交易、入金/出金的 `has_audit_log`） |

由此得出（后端计算，返回给前端）：
- **现金变动**：买入 = −金额；卖出 = +金额；转入 = 0.00。冻结变动恒为 0.00。
- **每股价格**（仅显示）：金额 ÷ 股数，四舍五入到 4 位小数（Q88）。例：1,500.65 ÷ 200 = 7.50325 → `7.5033`。转入显示为"每股成本"。
- **卖出的已实现盈亏、被卖出批次**：见下面 FIFO。

### 现金与流水
- 买入、卖出各产生一条现金流水：时间 = 成交时间，金额 = 现金变动，来源类型"股票买入"/"股票卖出"，说明如 `买入 200 股 IXQZ`、`卖出 150 股 IXQZ`，带备注；能关联到这条股票记录。修改 → 更新这条流水（不新增）；删除 → 删除这条流水（同 FEAT-005）。
- 转入**不产生流水**，不影响总现金、冻结、可用。
- 现金汇总（总现金 / 冻结 / 可用）和流水余额把股票流水与入金/出金、期权流水一起按 `(时间, 录入顺序)` 计算。

### 批次与 FIFO（按账户 + 标的）
- **批次**：每笔买入、每笔转入是一个批次。批次有原股数、原成本（买入 = 实付；转入 = 总成本）、剩余股数、剩余成本。
- **顺序**：同一账户同一标的的全部股票记录按 `(时间, 录入顺序)` 重放；转入按它的时间（日期 00:00，Q86）排进 FIFO，不是排在最前面。
- **卖出**：按 FIFO 从最早的、剩余股数 > 0 的批次扣股数，直到扣满卖出股数：
  - 整个批次被扣完：这部分成本 = 该批次剩余成本；
  - 批次只被扣一部分：这部分成本 = 剩余成本 × 扣除股数 ÷ 剩余股数，四舍五入到分（ROUND_HALF_UP，Q87），批次剩余成本减去这部分；
  - 被卖出成本 = 各部分之和；**已实现盈亏 = 卖出实收 − 被卖出成本**。
  - 例（Q69）：批次 300 股、1,000.00，卖出 100 股实收 400.00 → 成本 333.33，盈亏 +66.67，批次剩 200 股、666.67。
  - 例（跨批次）：转入 100 股 750.00，之后买入 200 股 1,500.65；卖出 150 股实收 1,200.00 → 转入批次全部 750.00 + 买入批次 50 股 1,500.65 × 50 ÷ 200 = 375.1625 → 375.16；被卖出成本 1,125.16，盈亏 +74.84；买入批次剩 150 股、1,125.49。
- 批次、被卖出成本、已实现盈亏都在读取时按重放得出（同期权）；补录、修改、删除任何一条之后，之后的卖出按新的 FIFO 重新匹配、重新计算。

### 股票持仓
- 某账户某标的**当前**持股 > 0 就是一个股票持仓（持股 = 各批次剩余股数之和）。
- 每个持仓：标的、持股、总成本（各批次剩余成本之和）、每股平均成本（总成本 ÷ 持股，四舍五入到 4 位小数（Q88），只显示）、批次数、批次明细。
- 每个批次：来源记录 ID、来源类型（买入 / 转入）、时间（买入为美东日期时刻；转入为日期）、原股数、剩余股数、剩余成本、备注。按 FIFO 顺序。
- 排序：标的字母升序（与 FEAT-003 相同的字符序）。不分页、不筛选。
- 整体：股票持仓个数（标的数）。没有总成本合计（不同标的相加没有意义；市值在 M3）。

### 操作 1：新增股票记录
按顺序检查，任一失败就整笔拒绝、什么都不保存，返回能直接给用户看的中文原因（字段错误指出字段）：
1. **字段**：上表各项格式；买入/卖出时间不晚于当前，转入日期不晚于今天（美东）。
2. **持股（卖出，Q15）**：把本笔插入该标的的历史重放，卖出时点持股 ≥ 卖出股数，否则拒绝，如"持股不足：2026-11-13 09:00 卖出 IXQZ 151 股，当时持有 150 股"。
3. **之后的卖出（补录，Q15）**：插入后该标的之后的每一笔卖出仍不超过当时持股（补录较早的卖出会让之后的卖出不够），否则拒绝，如"补录后 2026-11-05 10:00 的卖出 IXQZ 150 股将超过当时持股 100 股"。
4. **现金（买入，Q68、Q19）**：把本笔插入全部现金记录按时间重放，从本笔时间起每个时点总现金、可用现金都 ≥ 0，否则拒绝，如"可用现金不足：需要 1,500.00；2026-11-03 10:00 时可用现金将变为 −500.00"（同 FEAT-007 出金的文案风格；不足的时点可能是之后的某个时点）。卖出和转入只会增加或不改变现金，可不检查现金。
- 成功：保存；买入/卖出新增一条流水；返回这条记录（含现金变动、每股价格；卖出另含被卖出批次、被卖出成本、已实现盈亏）。不写审计。

### 操作 2：修改股票记录
- **可改字段**：买入/卖出 = 股数、金额、成交时间、备注；转入 = 股数、总成本、日期、备注。标的、类型不能改（录错请删除后重录）。
- 字段校验同新增；提交内容与原记录完全相同 → 不保存、不写审计，提示"没有修改"。
- 把修改应用到全部历史上按 `(时间, 录入顺序)` 重放：
  - 该标的每个时点持股 ≥ 0、每一笔卖出不超过当时持股（Q15），否则拒绝，如"修改后 2026-11-05 10:00 的卖出 IXQZ 150 股将超过当时持股 140 股"；
  - 现金每个时点总现金、可用现金 ≥ 0（Q19），否则拒绝，提示时点和金额。
- 成功：更新记录和它的流水；之后的卖出按新 FIFO 重新匹配（已实现盈亏随之变化）；置上"有审计记录"；写一条审计记录。股票没有冻结，所以没有"连带变化"（Q42 的连带变化只记冻结变动）。

### 操作 3：删除股票记录
- 同样把删除应用到全部历史上重放，持股、卖出、现金任一不成立就拒绝（如删除一笔已被之后卖出用到、删掉后卖出不够的买入；删除一笔卖出后，之后的出金让可用现金为负："可用现金不足：删除后 2026-11-07 10:00 时可用现金将变为 −100.65"）。
- 成功：删除记录和它的流水（如有）；之后的卖出重新匹配；写一条审计记录（修改前的完整内容）。
- 被删除或不存在的记录再被修改、删除、按 ID 查询 → "不存在"。

### 审计
- 审计对象类型新增"股票交易"（对象 = 股票交易 + ID）；按对象筛选可选它。
- 修改前 / 修改后的完整内容：类型、标的、股数、金额（转入为总成本）、时间（转入为日期）、备注、现金变动。改动的字段如 `金额：1,500.65 → 1,500.00`、`日期：2026-10-01 → 2026-11-04`。
- 摘要如 `买入 IXQZ 200 股`、`卖出 IXQZ 150 股`、`转入 IXQZ 100 股`。
- 已删除的股票记录在审计记录页仍能看到。

### 现金重放的影响范围（对已有功能）
股票买入/卖出加入现金重放后，所有已有的现金检查都要把它们算进去：入金/出金的新增、修改、删除（FEAT-007/005），期权开仓的可用现金检查（Q18）、平仓、到期作废的删除（FEAT-001/004/012）。例：可用现金被股票买入用掉后，STO put 的担保检查、出金都按扣除后的可用现金判断。

### 查询
- **股票交易列表**：当前账户的全部股票记录。排序：时间倒序，同一时间后录入的在上。分页同 FEAT-002（页码从 1，每页 1–100，默认 20，超过最后一页返回空列表）。

  - 每条：ID、类型、标的、股数、金额、现金变动（带符号）、每股价格、时间（UTC + 美东本地；转入另给日期）、备注、有审计记录；卖出另含被卖出成本、已实现盈亏、被卖出批次（每个：来源记录 ID、来源类型、批次时间、扣除股数、这部分成本）。
- **按 ID 查询**一条股票记录：同上。
- **股票持仓**：见上。
- **资金流水**：新来源类型"股票买入""股票卖出"，能关联到股票记录 ID。
- **审计记录**：新对象类型"股票交易"。
- 所有查询和操作只针对当前账户（Q53）。用另一个账户的记录 ID 请求 → "不存在"。

### 与现有期权功能的关系
- **没有任何联动**：股票持仓不影响卖出 call（FEAT-038 的规则不变：STO call 仍不冻结现金、**仍不检查股票覆盖**）；有空头 call 时股票照样可以全部卖出（不锁定）。覆盖检查和锁定在 FEAT-039。
- 期权的交易列表、持仓的期权部分、已平仓、盈亏汇总、首页的数字都不变（股票盈亏并入在 FEAT-040）。
- 唯一的文字改动：录入交易页 STO call 的提示（Q61）里"股票持仓功能（FEAT-011）上线后将自动检查"在本需求上线后不再准确，改为"covered call 覆盖检查（FEAT-039）上线后将自动检查"，其余文字不变。

## 页面与交互（给 frontend）

### 导航与入口

## 验收标准
"现金汇总"= 总现金 / 冻结 / 可用。后端测试固定时钟 **2026-11-13 10:00（美东）**；E2E 用真实时钟（以下日期都早于 2026-11-13，可直接使用；"晚于当前"的用例 E2E 用运行时刻 + 1 天）。以下标的都是虚构的。除注明外都在默认账户、从空库开始。

**场景 S**：按顺序录入：

| 编号 | 类型 | 标的 | 股数 | 金额 | 时间（美东） |
|------|------|------|------|------|-------------|
| D1 | 入金 | — | — | 10,000.00 | 2026-11-02 10:00 |
| S1 | 转入 | IXQZ | 100 | 总成本 750.00 | 日期 2026-10-01 |
| S2 | 买入 | IXQZ | 200 | 实付 1,500.65 | 2026-11-03 10:00 |
| S3 | 买入 | XYZ | 300 | 实付 1,000.00 | 2026-11-04 10:00 |

现金汇总 **9,099.35 / 0.00 / 9,099.35**（10,000.00 − 1,500.65 − 1,000.00 + 1,200.00 + 400.00）。

1. **录入与股票持仓**

   **Then** S1 时间存为 `2026-10-01T04:00:00Z`（Q86）；录入 S1 前后现金汇总都是 10,000.00 / 0.00 / 10,000.00。

## 边界情况
- **一笔卖出跨多个批次**：转入 + 买入（验收 2）；批次被扣一部分时按比例四舍五入（Q69）。
- **同一批次多次部分卖出**：最后一次用剩余成本，不差一分（验收 4，Q87）。
- **转入**：不影响现金、没有流水；按日期 00:00 参与 FIFO，不一定排在最前（验收 7、8，Q86）；日期可以是今天，不能是未来。
- **补录 / 修改 / 删除较早的记录**：持股和现金都按 `(时间, 录入顺序)` 重放检查，之后的卖出按新的 FIFO 重新匹配（验收 5、6、8、9）。
- **同一时间的买入和卖出**：按录入顺序（验收 10）。
- **冻结的现金**：不能用于买股票（验收 5）。
- **周末 / 假日 / 盘后**：股票买卖不检查交易日和交易时段，只要不晚于当前。
- **深夜成交**：列表筛选按美东日期（同 Q33）。
- **夏令时**：转入的 00:00 美东按当天时区换算（EDT → 04:00Z，EST → 05:00Z）。
- **标的与期权相同**：股票 IXQZ 与 IXQZ 的期权互不影响（验收 13）。
- **卖光后再买入**：持仓消失后再买入是新的持仓，FIFO 从新批次开始。
- **每股价格除不尽**：只用于显示，四舍五入到 4 位（Q88）；成本和盈亏只用分。
- **多账户**：股票持仓、FIFO、现金按账户独立（验收 12）。
- **被指派 / 行权得到或交出股票**：不在本需求（FEAT-013/014），以后同样作为批次 / 卖出参与这里的 FIFO 和 Q69。
- **股息**：不在本需求，先用入金 + 备注记录（Q26），不计入成本或盈亏。
- **拆股**：不在本需求（FEAT-028）。

## Out of Scope
- covered call 股票覆盖检查与锁定（FEAT-039，Q77–Q79）
- 被指派、行权生成股票（FEAT-013、FEAT-014）

- 行情、市值、未实现盈亏（M3）
- 交易日 / 交易时段检查（FEAT-009）
- 全部账户合并查看（FEAT-035）；CSV 导入（FEAT-030）
- 任何券商接入

**设计决定**
- 股票记录单独一张表、独立 id 序列；持股按 `(traded_at, 股票记录 id)` 重放，现金仍按 `(occurred_at, 流水 id)` 重放。买入/卖出与其流水在同一事务写入，两种顺序一致；所以"入金/出金、期权、到期作废、股票记录共用同一时间按录入顺序"由已有的统一流水实现，已有的所有现金检查（入金/出金、STO put Q18、平仓、修改、删除）自动把股票流水算进去，无需改动那些代码。
- 批次、被卖出成本、已实现盈亏、持仓都不落库，读取时按 FIFO 重放（同期权 Q39 的做法），补录/修改/删除后自动重新匹配。
- 所有写操作先拿账户的 `cash_account` 行锁（转入、卖出也拿），与该账户其它写操作串行。
- 修改请求可以带 `symbol` / `type`：与原记录相同则忽略，不同则 422（验收 8"直接请求修改标的或类型 → 被拒绝"）。
- 新增买入的现金不足文案**总是**用"需要 X；<时间> 时可用现金将变为 Z"的形式（按验收 5 的原文 `可用现金不足：需要 600.00；2026-11-03 10:00 时可用现金将变为 −80.00`），即使不足的就是本笔时点；这与 FEAT-007 出金在本笔时点不够时的 `需要 X，可用 Y` 不同，已在契约里注明。
- 审计改动字段：股数、金额（转入显示为"总成本"）、时间（转入为"日期"）、备注；`cashChange` 只在修改前/后完整内容里，不单独列为改动（验收 8 只出现一条 `金额：…`）。

**做法**
- 所有数字（金额、现金变动、每股价格、平均成本、被卖出成本、已实现盈亏、批次）都取后端值，前端只格式化；每股价格 / 平均成本原样显示后端的 4 位小数；股数用 `formatInteger` 加千分位。
- 金额列：买入/卖出显示带符号的 `cashChange`（正绿负红），转入显示 `总成本 750.00`，不带符号不着色；已实现盈亏只有卖出有（正绿负红），其它 `—`。时间：转入显示 `tradeDate`，其它显示 `tradedAtLocal` 到分钟。
- 录入表单：类型无默认值；买入/卖出用 `tradedAtLocal`（`datetime-local`，默认当前美东时间），转入用 `tradeDate`（`date`，默认今天美东）；按类型只发送对应的时间字段；金额标签随类型变化。只做格式校验（文案同契约），不预测现金、持股、盈亏；后端字段错误显示到同名字段，422 原文显示在按钮上方，保留输入。
- 修改对话框：类型、标的只显示（提示"标的或类型录错请删除后重新录入"），不发送 `symbol` / `type`；每次发送全部可改字段（股数、金额、时间或日期、备注）；`NO_CHANGES` 等 422 原文显示、对话框不关。删除用通用确认框，摘要如 `卖出 150 股 IXQZ，2026-11-05 10:00，+1,200.00` / `转入 100 股 IXQZ，2026-10-01，总成本 750.00`。
