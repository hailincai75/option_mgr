# FEAT-041: 卖出 call 被指派

- **Status:** Verified
- **Priority:** P0
- **Depends on:** FEAT-013（卖出 put 被指派）、FEAT-011（股票）、FEAT-040（股票盈亏并入汇总）
- **Scope:**
  - [x] Backend: Done
  - [x] Frontend: Done

> **暂定口径：** 规则 3 的盈亏口径是按 put 对称推出的**暂定方案**，用户还没被指派过 call。第一次真的被指派 call 时，对照券商报表复核，不一致就改本需求（Q8）。

## 背景 / 用户故事
我卖 covered call，价内到期或提前会被指派，按行权价交出股票。我想在持仓页空头 call 行点"被指派"，系统按 FIFO 交出同一账户的股票，期权记 0.00，权利金并入股票卖出实收，股票盈亏出现在已平仓页和汇总里。FEAT-038 期间录入、没有对应股票的空头 call，要先录入股票才能被指派（规则 4）。

## 已定的口径
- Q8（暂定）：见规则 3。
- Q11：只支持股票 / ETF 期权。
- Q15：任何时点持股不能为负。
- Q21 / Q73：张数必须是指派时点最早 1 笔或连续多笔整批次之和。
- Q69 / Q87：交出股票按股票 FIFO，部分卖出按剩余成本比例分摊。
- Q74：可选指派费，默认 0.00，从卖出实收和现金中扣。
- Q75：持股不足 → 拒绝，提示先录入股票（规则 4）。
- Q76 / Q94 / Q95 / Q97 / Q98：日期、按钮时间窗、计入笔数、备注，同 FEAT-013。
- Q99：行权金额不是整分时向下取整到分（规则 2）。
- Q100：一次 call 被指派计 2 笔（规则 7）。

## 规则
沿用 FEAT-013：记录形式（"被指派"期权记录 + 生成的股票记录 + 一条现金流水，同生同灭）、字段与时间、按钮时间窗、整笔批次、与到期作废的先后（Q65）、删除（一条审计、可重记）、不可修改、生成的股票记录不能单独改删、重放与"连带变化"审计、按账户隔离（Q53）、前端不做计算。以下只写 call 的差异。

1. **对象**：空头 call（去掉 FEAT-013 中"卖出 call 的被指派暂不支持"的拒绝）；多头仍拒绝"多头持仓不能被指派（主动行权见 FEAT-014）"。
2. **行权金额** = 行权价 × 股数（股数 = 张数 × multiplier），不是整分时**向下取整到分**（Q99）。
3. **金额（Q8 暂定）**：
   - 权利金 = 被指派批次开仓净额之和。
   - 卖出实收 = 行权金额 + 权利金 − 指派费。
   - 交出成本 = 同一账户该标的按股票 FIFO 取的成本（可跨批次、部分卖出一个批次）。
   - 股票已实现盈亏 = 卖出实收 − 交出成本（可为负）；期权已实现盈亏恒为 0.00。
   - 现金变动 = +（行权金额 − 指派费）（权利金开仓时已收）；冻结不变。
4. **持股检查（Q75、Q15）**：插入后按 `(时间, 录入顺序)` 重放：
   - 指派时点持股 < 股数 → 拒绝"持股不足：被指派需要 300 股 IXQZ，2026-11-20 16:00 时持有 150 股。请先录入股票（转入或更早的买入）"。更晚的、或同一时间但更晚录入的买入不算。
   - 之后已有的股票卖出 / 被指派因此超过当时持股 → 拒绝，文案同 FEAT-011（如"补录后 2026-11-24 10:00 的卖出 IXQZ 100 股将超过当时持股 0 股"）。
   - 检查顺序：在 FEAT-013 的"整笔批次"之后、"现金"之前。
5. **生成的股票记录**：新类型 **"指派卖出"**，时间 = 指派时间，股数，实收 = 卖出实收，关联被指派 ID；像普通卖出一样参与 FIFO、重放并产生股票盈亏（FEAT-040）。
6. **重放连带**：修改被指派批次净额 → 卖出实收变；补录 / 修改 / 删除更早的股票记录 → 按新 FIFO 重新匹配交出批次；使持股不足 → 拒绝并提示先删除该被指派，如"删除后 2026-11-20 16:00 的被指派 3 张 IXQZ 2026-11-20 9 C 需要 300 股，当时持股 150 股，请先删除该被指派"。卖出实收或交出成本变化写进审计连带变化，如 `被指派 #12 股票卖出实收 2,785.00 → 2,790.00`。
7. **笔数（Q100）**：一次 call 被指派在已平仓页为 2 行、计 2 笔：期权行 0.00（Q97）+ 股票"指派卖出"行（FEAT-040）；盈亏汇总、首页同样计 2 笔。

## 需要的数据和操作（给 backend）
- **记录被指派**：输入同 FEAT-013。返回：合约、张数、指派时间（UTC + 美东）、被指派批次、权利金、股数、行权金额、指派费、卖出实收、交出的股票批次（来源类型、时间、股数、成本）、交出成本、股票盈亏、现金变动、期权盈亏 0.00、股票记录 ID、备注。
- **删除**：同 FEAT-013；交出的股票恢复为持仓。审计摘要如 `被指派 IXQZ 2026-11-20 9 C 3 张（卖出 300 股 IXQZ）`，修改前内容含规则 3 各金额。
- **持仓**：空头 call 的"可以被指派"、可选张数、日期默认 / 最晚值（同 FEAT-013），另给该标的**当前持股**。
- **查询**：交易列表、已平仓（期权行另给卖出实收）、股票列表（类型"指派卖出"可筛选、关联被指派 ID、不可改删）、资金流水（来源"被指派"，说明如 `被指派 3 张 IXQZ 2026-11-20 9 C，卖出 300 股 IXQZ`）、审计，做法同 FEAT-013。

## 页面与交互（给 frontend）
沿用 FEAT-013 各页面的样式，差异：
- **持仓页**：空头 call 行按后端标志显示"被指派"。
- **对话框**：只读信息"冻结现金"换成"当前持股 300 股 IXQZ"；指派费说明"从卖出实收中扣"；说明段："按行权价按 FIFO 交出股票；卖出实收 = 行权价 × 股数 + 权利金 − 指派费，期权已实现盈亏记 0.00（暂定口径）。持股不足时请先录入股票。"结果显示返回的各项和交出批次表。
- **交易列表**：小字 `卖出 300 股 IXQZ，现金 +2,700.00`（有指派费加 `，指派费 5.00`）；冻结列 `—`。
- **已平仓页**：期权行小字 `权利金已计入股票卖出（300 股 IXQZ，实收 2,785.00）`；股票行标签 `指派卖出`、链接 `来自被指派 #12`；页面说明补一句 call 口径（暂定）。
- **股票页**：标签 `指派卖出`，金额列 `实收 2,785.00`，盈亏照常显示；无修改 / 删除，提示"由被指派生成，在交易列表删除"。

**场景 C**（默认账户）：入金 10,000.00（2026-11-02 10:00），按顺序：

| 编号 | 记录 | 时间（美东） |
|------|------|------|
| S1 | 买入 IXQZ 150 股，1,200.00 | 2026-11-03 10:00 |
| S2 | 买入 IXQZ 150 股，1,350.00 | 2026-11-04 10:00 |
| C1 | STO IXQZ 2026-11-20 9 C，2 张，净额 60.00 | 2026-11-05 10:00 |
| C2 | STO IXQZ 2026-11-20 9 C，1 张，净额 25.00 | 2026-11-06 10:00 |
| L1 | BTO IXQZ 2026-11-20 10 C，1 张，净额 15.00 | 2026-11-06 11:00 |

现金汇总（总 / 冻结 / 可用）**7,520.00 / 0.00 / 7,520.00**；IXQZ 300 股、2,550.00。

1. **按钮（Q95）**：时钟 2026-11-17 10:00，9 C 行有 `平仓`、`被指派`，10 C 没有 `被指派`；2026-11-20 16:30，9 C 行只有 `被指派`。对话框（2026-11-23）：张数选项 `2 张（200 股）`、`3 张（300 股）`，默认 3；日期默认 2026-11-20；显示"当前持股 300 股 IXQZ"。请求被指派 10 C → 拒绝"多头持仓不能被指派（主动行权见 FEAT-014）"。

2. **全部被指派**：时钟 2026-11-23 10:00，被指派 3 张、日期 2026-11-20、费用 0.00 → 记在 `2026-11-20T21:00:00Z`；权利金 `85.00`、行权金额 `2,700.00`、实收 `2,785.00`、交出 S1 150 股 1,200.00 + S2 150 股 1,350.00、成本 `2,550.00`、股票盈亏 **`+235.00`**、期权 `0.00`、现金 `+2,700.00`。现金汇总 **10,220.00 / 0.00 / 10,220.00**；无 9 C 持仓、无 IXQZ 股票。已平仓页 2 行：股票 `指派卖出` `+235.00` 在上、期权 `被指派` `0.00` 在下，`共 2 笔`、合计 `+235.00`；首页 `+235.00（2 笔）`。审计无新记录。

3. **提前指派、指派费、部分卖出股票批次**：时钟 2026-11-19 10:00。被指派 1 张 → 拒绝"必须一次被指派整笔开仓：最早一笔是 2 张，可为 2 张或 3 张"。被指派 2 张、日期 2026-11-18、费用 5.00 → 实收 `1,855.00`、交出 S1 150 股 1,200.00 + S2 50 股 450.00、成本 `1,650.00`、盈亏 `+205.00`、现金 `+1,795.00`；现金汇总 9,315.00 / 0.00 / 9,315.00；剩 IXQZ 100 股 900.00、C2 1 张。时钟 2026-11-23 作废 9 C → 1 张 `+25.00`。

5. **使之后卖出不成立**：场景 C 加卖出 IXQZ 100 股、实收 1,000.00（2026-11-24 10:00），时钟 2026-11-25。被指派 3 张（2026-11-20）→ 拒绝"补录后 2026-11-24 10:00 的卖出 IXQZ 100 股将超过当时持股 0 股"；被指派 2 张 → 成功。

6. **删除与不可修改**：第 2 条之后删除被指派 → 现金汇总 7,520.00 / 0.00 / 7,520.00；9 C 恢复 3 张；IXQZ 恢复 300 股 2,550.00（S1、S2）；股票页、已平仓、资金流水中消失；审计一条，摘要 `被指派 IXQZ 2026-11-20 9 C 3 张（卖出 300 股 IXQZ）`。修改被指派 → 拒绝"被指派不能修改，记错请删除后重新记录"；改 / 删生成的股票记录 → 拒绝"该股票记录由被指派生成，请在交易列表删除对应的被指派记录"。

7. **重放**（各从第 2 条之后）：
   - C2 净额 25.00 → 30.00 → 实收 `2,790.00`、盈亏 `+240.00`；现金汇总 10,225.00 / 0.00 / 10,225.00；审计连带变化含 `被指派 #<ID> 股票卖出实收 2,785.00 → 2,790.00`。
   - 补录转入 IXQZ 100 股成本 700.00（2026-11-01）→ 交出 转入 100 股 700.00 + S1 1,200.00 + S2 50 股 450.00，成本 `2,350.00`、盈亏 `+435.00`；剩 100 股 900.00。
   - 删除 S2 → 拒绝"删除后 2026-11-20 16:00 的被指派 3 张 IXQZ 2026-11-20 9 C 需要 300 股，当时持股 150 股，请先删除该被指派"；补录卖出 100 股（2026-11-10 10:00）→ 同样被拒（持股 200 股）。被拒的都不变、不写审计。

8. **multiplier ≠ 100、取整（Q99）**：新账户：入金 100.00（2026-11-02 10:00）；转入 QFZ 2 股成本 20.00（2026-11-02）；STO 1 张 QFZ 2026-11-20 12.345 C，multiplier 1，净额 0.50（2026-11-03 10:00）。被指派 1 张 → 行权金额 `12.34`、实收 `12.84`、交出 1 股成本 `10.00`、盈亏 `+2.84`、现金 `+12.34`；流水说明 `被指派 1 张 QFZ 2026-11-20 12.345 C（multiplier 1），卖出 1 股 QFZ`。

9. **账户隔离、格式**：默认账户按第 2 条被指派后，第 4 条的"小账户"（未录股票）9 C 仍 1 张、被指派仍因持股 0 股被拒；在"小账户"用默认账户的被指派 ID 删除 → "不存在"。指派费 `−1.00` / `1.234`、日期为空、备注 501 字符、张数 0 → 都被拒绝、错误显示在字段下。

## 边界情况
- 日期、时间窗、夏令时、周末假日、多批次、与作废的先后：同 FEAT-013。
- 交出 put 被指派得到的"指派买入"批次（wheel）：照常按 FIFO。
- 同一时间 16:00 在被指派之后录入的买入不算持股（规则 4）。
- 股票盈亏可为负。
- 持股不足只能先补录股票，系统不自动生成。
- 覆盖 / 占用股票（Q77–Q79）由 FEAT-039 做；本需求只按 FIFO，不看被哪张 call 覆盖。
- 指数期权不支持（Q11）；拆股见 FEAT-028。

## Out of Scope
- 覆盖检查与股票锁定（FEAT-039）、主动行权（FEAT-014）、批量到期（FEAT-015）
- 指定交出哪批股票；拆分期权批次（Q73）
- 修改被指派记录；单独改删生成的股票记录
- 自动判断价内 / 自动生成被指派；Wheel 视图（FEAT-026）；合并查看（FEAT-035）；券商接入
