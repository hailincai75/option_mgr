## 待确认（等用户决定）
- **修改 STO put 时什么情况下重新检查 Q18**（后端 Implementation Notes 的 Open issue）。现在的实现：只有张数、multiplier 或成交时间变了才检查；只改净额或备注不检查。按现在的实现测试，结果符合实现（`q41_editedStoPutQ18OnlyWhenCollateralInputsChange`）：
  - 场景 A 中先把 D1 改为 59,000（Q41 允许），这时 L2 之前的可用现金只有 19,698.70，小于担保 20,000。
  - 之后只改 L2 的备注或净额 → 成功。
  - 改 L2 张数为 2 → 被拒："可用现金不足以担保卖出 put：需要 40,000.00，可用 19,698.70"。
  - 把 L2 时间改晚 1 分钟 → 被拒："需要 20,000.00，可用 19,698.70"。
  - 如果用户决定"只要修改 STO put 就重新检查 Q18"，前两项的期望就要改成被拒，需要后端改代码、QA 再复测。
- 不影响验收标准：13 条验收标准里没有覆盖这种情况。
