## 疑问 / 需求不清楚的地方
1. 指派日期输入框带有 `max`（= 后端给的最晚日期）。填更晚的日期（晚于到期日，或今天 16:00 之前填今天）时，浏览器会阻止提交并显示原生提示，不发请求，所以页面上看不到后端文案"指派日期不能晚于到期日（…）"/"指派日期为今天时，美东 16:00 之后才能记录"。这符合"最晚只能选后端给的最晚日期"；后端文案已由 API 测试覆盖。如果希望页面上显示中文原因，需要 frontend 调整。
